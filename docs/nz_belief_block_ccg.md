# belief 블록 CCG (dromu): follower 반응이 x 를 따라가는 하한 (2026-11-21)

입지 게임 가치 계열 (`nonzero_sum/loc_tkp.jl`, 지리 1, Coupled-DR r = 0.2, S = 10, |X| = 8,464) 에서
원고 알고리즘 1 의 belief cut 이 국소적이라 열거로 퇴화하는 문제 (`docs/nz_cut_locality_2026-11-20.md`) 를 피하려고 만든 방법을 정리한다.
원고에 본 알고리즘으로 넣을지, 비교 기준 (benchmark) 으로 쓸지는 결정 전이다.

## 1. 한 줄 요약

belief 를 하나씩 생성하는 바깥 루프는 원고와 같다. 모은 belief 를 마스터에 넣을 때 affine cut 한 줄 대신
**follower 문제의 사본 전체 (원문제 변수 + 쌍대 변수)** 를 넣고, follower 최적성은 **min 안의 벌점** 으로 처리한다.
그래서 마스터 안에서 follower 반응이 x 에 따라 다시 최적화되고, belief 하나가 많은 x 의 하한을 한꺼번에 올린다.
분류로는 Benders 가 아니라 column-and-constraint generation (CCG, Zeng–Zhao 2013 계열) 이다.

## 2. 기호

belief b = (p, ν, p̃) ∈ 𝔅 (원고 Step 3). 블록에 쓰는 것은 follower belief d := p̃ 와 리더의 CVaR 가중 r := ν.

- follower 의 실행가능 집합 (x 는 우변에만)
  Y(x) = { (h, y) : h ∈ H,  A y_s − B h ≤ u_s + G_s x  (s = 1, …, S) }
- follower 비용 C_F(h, y) = c_Fᵀ h + Σ_s d_s d_Fᵀ y_s, 최소값 V_F(x) = min_{Y(x)} C_F
- 리더 비용 C_L(y) = Σ_s r_s d_Lᵀ y_s (입지에서는 수입의 음수)
- belief 고정 비관 값 V_b(x) = max { C_L(h, y) : (h, y) ∈ Y(x), C_F(h, y) = V_F(x) }

원고 Lemma response 와 CVaR 쌍대 (식 cvar-dual) 에서 V*(x) = max_{b ∈ 𝔅} V_b(x) 이다.
(d_s > 0 이면 follower 최적 (h, y) 의 y_s 는 각 시나리오에서 recourse 최적이라, 위의 max 는 원고의 Σ_s ν_s φ(x, h, ξ^s) 와 같다.
상자 제약 |p̃_s − q̂_s| ≤ ε̃/√S 때문에 이 계열에서는 늘 d_s ≥ 0.037 > 0.)

## 3. 블록: min 안의 벌점

### 3.1 최적성 조건을 벌점으로
follower 최적성 간격 gap(h, y) := C_F(h, y) − V_F(x) ≥ 0 은 follower 최적일 때만 0 이다. 조건을 지우고 간격에 벌점 μ ≥ 0 을 붙인다.

  LB_b(x) := min_{(h, y) ∈ Y(x)} [ C_L(y) + μ · gap(h, y) ]

- **하한 (모든 μ ≥ 0)**: follower 최적해 (h*, y*) 를 넣으면 gap = 0 이므로 LB_b(x) ≤ C_L(y*). 따라서 LB_b(x) ≤ V_b(x) ≤ V*(x).
- **정확성 (μ 가 크면)**: LB_b(x) 는 LP  min{ C_L : (h, y) ∈ Y(x), C_F ≤ V_F(x) } 의 라그랑주 완화이다. LP 강쌍대로 최적 승수 μ* 가 있고
  μ ≥ μ* 이면 LB_b(x) = 그 LP 값이다. 승수의 실행가능 영역은 x 와 무관하므로 (x 는 우변에만) 꼭짓점이 유한하고,
  x 와 무관한 균일 문턱 μ̄_b 가 있다 (원고 Lemma phi (ii) 와 같은 논법).
- μ 가 문턱보다 작아도 하한은 유효하다. 수렴만 느려질 뿐 틀린 답을 내지 않는다.

작은 예: follower 선택 A (follower 비용 100, 리더 비용 50), B (101, 10). 진짜 값 50.
LB = min(50 + 0·μ, 10 + 1·μ) = min(50, 10 + μ). μ = 10 이면 20 (유효하지만 느슨), μ ≥ 40 이면 50 (정확).

### 3.2 비관 동률: η 섭동 (η 는 원고의 반지름 ε 와 무관한 작은 섭동 크기)
위 LB 는 follower 최적해 중 리더에게 가장 유리한 것 (낙관) 의 하한이다. 비관 (리더에게 가장 불리한 것) 을 잡기 위해
follower 비용을 C_F^η := C_F − η C_L 로 바꾼다. η 가 충분히 작으면 C_F^η 의 최소해는 C_F 최적해 중 C_L 최대인 것이므로

  LB_b(x) := min_{(h, y) ∈ Y(x)} [ μ C_F^η(h, y) + C_L(y) ] − μ V_F^η(x),   V_F^η(x) := min_{Y(x)} C_F^η

는 V_b(x) 의 하한이 된다. 동률을 깨는 데 드는 승수는 약 1/η 이므로 μ ≥ 1/η 가 필요하다.
즉 문제는 비관 그대로이고, 벌점 블록 자체는 낙관형 (μ 가 크면 follower 최적해 중 리더에게 유리한 쪽으로 감) 이다.
섭동 문제에서는 최적해가 유일해 낙관과 비관이 같으므로, 섭동 문제의 낙관형 블록이 원래 문제의 비관 값 V_b(x) 까지 올라간다.
η 가 너무 크면 follower 에게 진짜 차이 나는 선택까지 뒤집혀 하한이 깨지므로, η 는 그런 차이를 건드리지 않을 만큼 작아야 한다.

### 3.3 마스터에 넣는 방법
- 첫 항: belief 마다 (h, y) 의 사본을 마스터 변수로 둔다. x 는 Y(x) 의 우변에만 있어 선형.
- 둘째 항: V_F^η(x) 를 LP 쌍대로 쓰면 −μ V_F^η(x) = μ · min_{(π, κ, ω) 쌍대 실행가능} D(π, κ, ω; x),
  D = Σ_s (u_s + G_s x)ᵀ π_s + wᵀ κ + h^Uᵀ ω. 곱 x · π 는 McCormick (ψ ≥ π − U(1 − x), ψ ≥ 0) 으로 바꾸고, 정수 x 에서 정확하다
  (상한 U 안에 최적 쌍대가 있으면 충분, `loc_tkp.jl` 머리말).
- 두 항 모두 min 이므로 마스터 (min) 에 쌍대화 없이 그대로 들어간다. 원고는 max 안의 벌점을 쓰므로 Step 3 의 쌍대화가 필요했다.
- 추가 강화: 거점-고객 호 단위 제약 y^R_ij,s + y^S_ij,s ≤ ξ_j,s Σ_k x_ik (정수 x 에서 중복, LP 완화 강화).

마스터 (belief 집합 𝒞):

  min_{x ∈ 𝒳} c_Lᵀ x + t0   s.t.  t0 ≥ LB_b(x)  (b ∈ 𝒞)

## 4. 알고리즘

```
𝒞 ← {명목 belief};  UB ← +∞
반복:
  마스터를 풀어 x̂, t0, 하한 LB 를 얻는다 (Gurobi 하한)
  UB − LB ≤ 0.5% 이면 끝 (Optimal)
  [싼 탐색] x̂ 에서 후보 belief (𝒞, 두 성분 이동, 무작위 40 개) 마다
      g(x̂, d) = (d 에서 follower 최적 반응 α 를 구하고, α 를 최적으로 만드는 belief 위에서 α 의 정확 값) ≤ V*(x̂)
    를 병렬 LP 로 계산, 최고 후보에서 belief 를 바꿔 가며 4 회까지 개선
    g > t0 + 0.1% 이면 그 belief 를 𝒞 에 추가하고 다음 반복
  [oracle] α-B&B (원고 4.3 절, Ω 위의 공간 분지한정) 로 V*(x̂) 를 푼다
    UB ← min(UB, c_Lᵀ x̂ + V*(x̂) 의 상한)
    최악 belief 가 t0 보다 나쁘면 𝒞 에 추가, 아니면 상한 증명으로 끝
```

- 하한은 §3 에 따라 늘 유효, 상한은 원고 Corollary conservative bounds 에 따라 유효.
- 유한 종료: 원고 Thm finite-type 에 따라 유한 개 belief 로 충분하다 (실측 11 개).

## 5. 원고 재정식과의 관계

| 원고 | 마스터 (하한) | oracle (상한) |
|---|---|---|
| Lemma response, CVaR 쌍대, 𝔅 | 씀 | 씀 |
| Thm finite-type, Prop belief (iii) | 씀 (belief 생성의 근거) | – |
| Lemma phi (θ 벌점) | 안 씀 | 씀 |
| Step 1 (λ 벌점, Prop certificate) | 안 씀 (반대 방향 벌점) | 씀 |
| Step 2 McCormick | 씀 (V_F 쌍대) | 씀 |
| Step 3 쌍대화 → Ω, Thm minimax | 안 씀 | 씀 |
| belief cut v(x; b, t) | 블록으로 대체 | – |
| α-B&B | – | 씀 |

원고의 벌점 V*_λ = sup [리더 위험 − λ·gap] 는 위에서, 블록 LB_b = min [리더 비용 + μ·gap] 는 아래에서 V* 를 끼우는 짝이다.

## 7. 한계와 주의점

1. **마스터의 암묵적 열거.** McCormick 쌍대 항 때문에 분수 x 에서 마스터가 얻는 "횡재" 가 μ × 용량 가치 × 크기 (거점당 수만 단위) 로
   값 차이 (수백) 보다 크다. 그래서 잎 근처 전에는 가지치기가 거의 안 된다. MIP 관점의 반론 (지수적 증가) 은 남는다.
2. **μ ≈ 10 이 필요한 이유.** 적대 belief 는 follower 를 거의 무차별하게 만든다 (x* 에서 follower 비용 0.148, 상대 1.3e-7 차이로 리더 비용 9.6 이동).
   비관을 재현하려면 μ ≥ 1/η, 엄격한 비관 (허용오차 0) 이면 μ ≥ 65 수준.
3. **η 의 정확성은 수치 확인뿐.** 충분히 작은 η 의 존재는 유한 꼭짓점 논법으로 보장되지만 값은 계산하지 않았다.
   η = 0.1 은 평가기 (α-B&B 의 정확 평가) 와 일치하고, 두 쪽 모두 상대 1e-7 안의 거의 동률을 동률로 취급한다. 허용오차 0.5% 와 같은 크기의 수치 모호성.
4. **검증 범위.** 지리 1 만 풀었다. 다른 지리 (특히 x* 상한 증명이 병목이었던 지리 5) 는 미확인.

시도했으나 효과 없던 마스터 강화 (자세한 것은 `docs/nz_cut_locality_2026-11-20.md` 5c·5d 절):
- 구조 cut (단조 + 부분가법): 약정이 시나리오 공통이라 보완 관계가 생겨 무효 (반례, 실측 위반 최대 8%).
- 용량 쌍대 상한 조이기 (max_j (max_A c_Aj − c_ij)⁺, 기존보다 p 작음): 유효하지만 노드 변화 0.
- belief 마다 작은 μ 블록 추가: 노드 변화 0, 마스터 2 배.
- 낙관 블록 (η = 0, 모든 μ 에서 엄밀): x* 에서 평가기와 2.5% 차이라 0.5% 인증 불가.

- 부정확 마스터: gap 5% 에서도 노드가 나무 전체 그대로 → LP 하한이 잎 근처까지 incumbent 의 5% 안에 못 들어옴. 효과 없음.
- 해 풀: 한 번에 belief 를 여러 개 얻어 반복은 줄지만, 블록 수에 따라 마스터 한 번의 비용이 커져 (블록 5·10·11 개에서 162·397·745 s) 더 느림.
- 결론: 마스터 비용 ≈ (나무 전체 노드) × (블록 수에 비례하는 노드 LP 크기). 남는 지렛대는 블록 하나를 싸게 하거나 블록 수를 줄이는 것, 또는 하한 자체를 강하게 하는 것.
- 주의: 처음에는 해 풀 실행이 멈춘 것으로 잘못 판단했다 (진행 출력이 파일에 버퍼링되어 안 보였음). flush 를 넣어 고침.

| 기본 (목적값 하한 끔) | 7 | 8 | 868 s | 2 회 699 s | 반복 6 |
| 목적값 하한만 | 7 | 8 | 1,089 s | 1 회 573 s | 반복 7 |
| 목적값 하한 + i-C&CG (gap 2% → ×0.2) | 9 | 7 | 1,275 s | 2 회 714 s | 반복 4 (최적 x 를 노드 425 개, 42 s 마스터에서 찾음) |

- 목적값 하한은 마스터 값이 gap 안에서만 움직인 반복에서만 노드를 줄임 (629, 425 개). 대부분 반복은 값이 gap 보다 크게 움직여 나무 전체 그대로.
- i-C&CG 는 최적 x 와 UB 를 일찍 찾지만, 그 뒤 하한을 올리려면 gap 을 줄인 마스터를 나무 전체로 풀어야 해서 (241·248 s) 전체로는 더 느림.

- 구현: `obj_cut` (기본 켬), `early_gap`, `gap_shrink` 인자. 첫 구현은 부정확 incumbent 에서 belief 가 없으면 정확 모드에 고정하는 실수가 있었고, i-C&CG 대로 고침 (그 x̄ 에서 바로 oracle, gap 은 incumbent 가 UB 에 붙을 때만 축소).

| 하한 | wd 끔 | wd 켬 |
|---|---|---|
| (a) 마스터 LP (McCormick) | −8,448,518 | **−5,150** |
| (b) 논문 root cut 전부 (follower 값함수 z 의 X 위 볼록 껍질) | −2,206,694 | −2,741,287 |

- 그러나 후보지 7 곳 CCG 실행에서는 노드가 2,311 → 약 2,150 (−7%) 에 그치고 마스터 합은 446 → 530 s 로 오히려 늘었다. 남은 간격 (−5,150 대 정수 최적 −2,089) 은 분수 x 에서 사본이 여러 거점의 부분 용량으로 리더 수입을 만드는 "높은점" 몫이라, 잎 근처 전에는 가지를 못 친다.

## 11. 한 나무 (single-tree) 판: 블록을 cut 생성기로 (2026-11-21 밤, `nonzero_sum/nz_belief_ccg_tree.jl`)

마스터 무게 진단 (10 절: 마스터 비용 ≈ 나무 전체 노드 × 블록 수에 비례하는 노드 LP, 반복마다 나무를 처음부터) 에 대한 대응.
블록 L_b 를 마스터에서 빼고 belief 마다 LP 생성기 하나로 둔다 (x 는 고정 등식 x = x̄ 로 둔 변수).
값 v_b(x̄) 와 고정 등식의 쌍대 g_b 로 cut t0 ≥ v_b(x̄) + g_bᵀ(x − x̄). 블록 LP 값은 x (우변) 에 볼록이라 [0,1]ⁿ 전체에서 유효하고 정수 x̄ 에서 정확.

- 루트: LP 완화 위의 Kelley 분리 (30 회까지).
- 정수 후보 (lazy callback): 생성기를 모두 x̄ 에서 풀어 위반 cut. 위반이 없으면 싼 belief 탐색, 새 belief 가 값을 올리면 **나무 안에서** 생성기로 추가 (x̄ 확보: μ 키우기 → no-good).
- 나무 안에서 belief 가 늘면 incumbent 값이 옛 블록 기준이라 다시 푼다 (콜백 cut 은 실제 제약으로 옮김). 노드 하한은 그 시점 블록의 하한이라 objective_bound 는 그대로 유효.
- 나무 안에서 belief 가 안 늘었으면 incumbent 에서 α-B&B oracle (명시 판과 같음).
- 실행: `ALG=tree julia -t T,1 nonzero_sum/run_nz_belief_ccg.jl` (인자 ROOT_ROUNDS, UCUT, PAR). MW 는 아직 없음.

검사 (`scratchpad/gen_cut_check.jl`, 후보지 3 곳, |X| = 64, 명목·이동 belief, wd 켬): 정수점에서 생성기 값 = 명시 블록 (차이 1e-12),
cut 12 개의 정수점 64 개 최대 초과 9e-9 (LP 허용오차), 기울기 = 유한차분.
