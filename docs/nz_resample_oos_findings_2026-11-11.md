## 1. OOS 설계

### 1.1 common·보정형 OOS 는 Nominal 편

- common OOS 와 x 고정 보정형 OOS 는 모두 q̂ 를 중심으로 평가한다. 그래서 평균으로는 Nominal 이 구조적으로 유리하다.
  - 보정형 설정: 진짜 p ~ Dirichlet(n_eff q̂), n_eff = 30. follower belief 는 표본 N_F = 10 개의 경험분포이고, 그중 비율 ρ 를 리더와 공유한다.
- g72 시드 1 의 예: N 의 셋째 거점은 저수요 시나리오 3·4·7 에서만 손해를 본다. 적대 꼭짓점에 가려면 p₃ + p₄ + p₇ ≥ 0.6 이어야 하는데, 무작위 진짜 분포는 0.04% 만 거기에 간다.

### 1.2 재표본 (Esfahani–Kuhn) 설계

- **진짜 F:** 지역 요인 수요 모형을 그대로 쓴다. 시나리오 시드는 수요만 바꾸므로, 시드마다 같은 F 에서 뽑은 독립 학습 표본이 된다.
- **반복:** 시드 하나 = 학습 표본 하나.
  - N·D 는 정확 열거로 구한다.
  - C 는 certify-or-solve 로 구한다 (1.3 절).
- **OOS:** 진짜 F 에서 뽑은 시험 표본 2000 개를 모든 반복·모형이 공유한다 (시드 7770001, CRN). follower 는 표본 N_F = 10 중 비율 ρ ∈ {1, 0.5, 0} 를 리더와 공유하고, K = 10 번 반복한다.
- **지표:** 평균 진짜 비용, 인증값 준수율 P(J ≤ 인증값), C−N·C−D 쌍별 차.
- **주의:** TV 볼은 학습 표본의 지지점 위 분포만 담기 때문에 연속인 진짜 F 를 포함하지 못한다. 준수율은 경험적 지표일 뿐 보장이 아니다.

### 1.3 결합 해 확정 절차 (c3, best-first)

1. 결정 377 개 모두의 witness 하한을 belief q̂ 하나로 계산한다 (40~60 초).
2. 하한이 가장 낮은 결정부터 x 고정 α-B&B 로 평가한다 (한도 900 초).
3. 평가할 때마다 U (최선 상한) 를 갱신하고, 최악 belief 로 남은 결정의 하한을 올린다. 하한 ≥ U 인 결정은 제외한다.

결과:
- 처음 판 c2 보다 2~3 배 빠르다 (시드당 10~45 분).
- 2 단계 답과 대조한 4 건 중 3 건이 확정 일치했고, 나머지 1 건은 overlap 이었다 (모순 아님).
- **병목:** 3 거점 결정의 상한이 900 초 안에 닫히지 않는다.
- **overlap 규칙:** 최선 UB 규칙은 2 거점 결정 쪽으로 치우친다. best-witness 규칙으로 바꾸면 C 가 0.4~0.9%p 좋아지지만 결론은 바뀌지 않는다.

## 4. 세 정식화에서 유도한 구조

### 4.1 리더 손실

φ_s(x, h) = −v × (B 판매) 이다. A 점포 용량은 묶이지 않으므로 (RCR), B 판매는 B 상권의 수요에 대해 줄지 않는다. 따라서 손실 순위는 총수요가 아니라 **B 상권 수요** 의 순위다.

### 4.2 Data-DR = Nominal + 더 깊은 꼬리 위험척도

- D 는 follower belief 가 q̂ 로 고정이므로 h = h(q̂) 다. 즉 N 과 **같은 손실 벡터** L(x) = (φ_s(x, h(q̂)))_s 에 TV ∩ 상자 최악 가중을 씌울 뿐이다.
- ε = 0.3, Γ = 0.19, S = 10, β = 0.4 에서 최악 가중은 손실 상위 3 개 시나리오에 (0.29, 0.21, 0.10)/0.6 이다. N 은 상위 6 개를 균등 평균한다.
- 진짜 목적은 CVaR₀.₄ 이고, in-sample CVaR₀.₄ 가 그 일치 추정량이다. D 는 다른 범함수 (대략 CVaR₀.₇₅) 를 표본 3 개로 추정한다. 그래서 평균이 나쁘고 (편향) 시드 간 흔들림이 크다 (분산).
- 같은 분포 OOS 에서 D 가 N 을 이기려면 학습 분포보다 시험 분포의 꼬리가 무거운 **분포 이동** 이 필요하다.
- 비교: Goyal–Zhang–He (JOC 2023) 는 적률 집합 (γ₁ = 0 이라 평균 고정) 을 쓰고, 가치 주장도 "γ ↑ 이면 OOS 변동 ↓" 뿐이다. 평균 우위는 주장하지 않았다. 평균이 고정되면 적대자가 한쪽으로만 밀 수 없다.

### 4.3 결합: 진짜 경로 + belief 경로

최악 (진짜 a, belief d) 은 TV(a, d) ≤ δ 로 묶인다.
- **진짜 경로:** a 를 B 판매가 낮은 시나리오로 옮긴다. D 와 같은 경로다.
- **belief 경로:** d 로 소매상의 예약 h 를 B 에서 떼어 놓는다. 예약된 단위는 c, 예약 안 된 단위는 c + p 이므로, 예약이 B 에서 줄면 B 판매가 준다.

g72 시드 1 (ε = 0.3) 에서 C − D 를 분해하면 이렇다 (`why_worst.jl`).

| 결정 | N | D | C | belief 경로 | 진짜 쪽 |
|---|---|---|---|---|---|
| {9;10;11} (N1) | −2549 | −2057 | −1889 | +172 | −4 |
| {9;10} (D1) | −2191 | −2125 | −1897 | +228 | 0 |
| {8;10} (C) | −2156 | −2063 | −2011 | +55 | −3 |

- 결합의 추가 보수성은 거의 전부 belief 경로에서 온다.
- 최악 belief 는 리더에게 최악이 아닌 시나리오 (지역 1 수요가 높은 시나리오 1 과 시나리오 7) 에 질량을 둔다. δ = 0.1 을 다 쓴다.

### 4.4 결정이 갈리는 조건

belief 벌점을 Π(x) := V_C(x) − V_D(x) 라 하면, C 와 D 의 해가 다를 필요충분조건은 다음과 같다.

$$\exists\, x' :\ V_D(x') - V_D(x_D) < \Pi(x_D) - \Pi(x')$$

즉 (i) D 기준으로 1 위와 가까운 후보가 있고, (ii) 그 후보들의 Π 가 달라야 한다. Π > 0 이 되는 조건은 다음 네 가지다 (`why_contest.jl` 로 확인).

| 조건 | 내용 | g72 시드 1 확인 |
|---|---|---|
| P1 경합 시장 | \|c_Bj − c_Aj\| < p 인 시장에서만 예약 여부가 승자를 바꾼다. 차이가 p 이상인 독점 시장은 Π 에 기여하지 않는다. | B 독점 시장의 B 판매는 479 → 479 로 그대로, B 우세 경합 시장만 줄었다 |
| P2 예약 내부해 | 소매상 예약은 뉴스벤더 해 h_i = 사용량의 (1 − f/p) 분위다. 한도 w 에 걸리면 belief 에 둔감하다. | h(q̂) 가 모든 점포에서 0.75 분위와 같다. 사용량 503 ≫ 300 인 Winnipeg 는 고정 |
| P3 분위 계단 | h 는 d 에 대해 계단 함수다. 시나리오 10 개, f/p = 0.25 이면 여유가 0.05 라 δ ≥ 0.05 가 필요하다. | TV(a, d) = δ = 0.1 |
| P4 리더 꼬리 | 예약 감소가 최악 a 의 시나리오 (B 판매가 낮은 쪽) 에서 판매를 줄여야 한다. | {9;10} 은 시나리오 4 (가중 0.29) 에서 −58 |

**한쪽으로만 작용하는 잡음 (가설):** 내부해 예약 (Rochester 182, Utica 199, Salisbury 220) 이 모두 사용량 분포의 최댓값 고원에 있다. 그렇다면 follower 의 belief 오차는 예약을 내리기만 한다. 다만 재표본 OOS (ρ = 0) 에서 C 는 여전히 D 에 약 1% 졌다. 실제 평균 효과는 결합이 매기는 최악 벌점보다 훨씬 작다는 뜻이다 (정량화는 하지 않았다).

정리 (12 조합):
- **결정 규칙 (4.4 절) 은 12 조합을 모두 설명한다.**
- **p = 100 (경합 수요 50~100):** Π ≈ 0 이 되어 C = D 다. 극한 예측이 맞았다. overlap 은 판정 실패가 아니라 {9;13} 과 {9;10} 이 결합·Data-DR 모두에서 같은 값이라서 생긴 것이다.
- **p = 200:** C = N ≠ D (교정형) 가 나왔다. D 는 {9;13} 을 고르지만 이 결정의 벌점은 140 이고, N 의 {9;10;11} 은 벌점이 약 16 이라 결합은 N 쪽으로 돌아간다. {9;10;11} 은 기본 계열 g72 의 진짜 F 최선 결정이다 (p = 800 기준 순위, p = 200 진짜 순위는 계산하지 않음).
- **p = 400~800:** C = {8;10} ≠ D = {9;10} 이다.
- **p = 1600:** C = D 다. Π 가 사라져서가 아니라 (Π({9;10;11}) 123~167), D 의 1 위가 5~6% 앞서 근접 동률 조건 (i) 이 깨졌기 때문이다.
- **"p ↑ 이면 Π ↑" 는 결정별로만 성립하고 결정 간 비교로는 성립하지 않는다.** {9;10;11} 의 Π 는 p = 200 에서 약 16, 400 에서 158~211, 800 에서 172, 1600 에서 123~167 이다. p 가 N·D 의 결정 자체를 바꾸므로, 결합의 결정 변화는 Π 의 수준이 아니라 근접 후보들 사이의 Π 차이로 정해진다.
- **f/p:** p = 800 에서 {8;10} 의 Π 는 13 → 58 → 106~115 로 커지고 {9;10} 의 Π 는 205~233 으로 거의 그대로다. f/p 를 더 키우면 벌점 격차가 D 격차 62 아래로 내려가 결정이 합쳐질 것이라는 예측이 나온다 (미확인).
- **수치 주의:** p = 200 의 {9;10;11} 고정 평가에서 witness (−2108.09) 가 UB (−2109.26) 보다 1.2 높게 나왔다. rel_gap 1e-4 (약 0.2) 를 넘는 불일치라 B&B 의 LP 허용오차를 확인해야 한다. 판정에는 영향이 없다 (C 의 UB 가 다른 결정들의 witness 보다 낮음).
- 이 결과는 인스턴스 하나에서 얻은 것이다.

## 6. 남은 일과 열린 질문

- **p = 200 의 교정형 (C = N ≠ D):** 이 조합에서 진짜 F 순위와 재표본 OOS 를 돌리면, 결합이 Data-DR 을 고치는 경우의 OOS 가치를 직접 볼 수 있다.
- **일반화:** 다른 지리·시드에서도 P1~P4 와 4.4 절의 결정 규칙이 결정 차이를 설명하는지 확인해야 한다.
- **결합 모형 가치의 OOS 설계:** 다른 세션에서 진행했다. 결과는 7 절에 정리했다.
- **새 계열에서 C:** 로그정규 등 새 계열에서는 C 를 직접 돌리지 않았다. 싼 witness 선별 후 박빙인 시드만 확정하는 2 단계 안이 있다.
- **모형 변경 아이디어 (실험 목록 밖):** TV 볼에 평균 앵커 E_p[ξ] = ξ̄ 를 더해, 적대자가 한쪽으로만 밀지 못하게 하는 안.

## 7. 다른 세션에서 바꾼 OOS (같은 날 오후, 메모리 `nz_resample_oos_protocol.md` 기준)

세 설계 모두 파일럿 41 시드의 N·D·C 결정을 그대로 썼다.

| 설계 | 방법 | 결과 |
|---|---|---|
| 분포 이동 (`geo_oos_shift.jl`) | zero-sum Phase B 를 옮김. 학습 시나리오 위 α = γ(1 + ζ randn), p·d ~ Dir(α) 를 따로 뽑음 | 결합은 어디서도 q95 최소가 아니고, D 보다 7~20 나쁘다. 구간은 가장 좁지만 좋은 쪽 (q05) 이 줄어서다. zero-sum 의 "Product q95 최소" 는 입지에서 재현되지 않는다 |
| 치우친 belief (`geo_oos_bias.jl`) | follower 표본을 지역 요인 평균 이동 (±κ·0.9) 으로 치우침 | C vs N 은 −5.4~−0.4, C vs D 는 −0.4~−1.5. 최악 방향의 손해 자체가 모든 모형에서 1~3% 뿐이다 |
| δ 보정 진단 (`delta_diag.jl`) | 실제 어긋남을 리더 시나리오 위 TV 로 측정 | 실제 δ 는 0.37 로 모형 δ (0.1) 보다 훨씬 크지만, 실제 belief 의 평균 피해는 거의 0 이다. TV 가 방향을 못 가리기 때문이다 |
| 피해 기준 δ 보정 (`delta_calib.jl`) | 적대 피해 = 실제형 피해의 분위가 되도록 δ 를 고름 | 진행 중 |

**4 절 구조와의 연결:**
- δ 진단의 "TV 가 방향을 못 가린다" 는 4.3·4.4 절과 같은 이야기다.
- 결합의 벌점은 소매상 예약을 B 에서 떼는 **특정 방향** 의 belief 에서만 생긴다 (P1~P4). 실제 belief 오차는 TV 로는 멀어도 그 방향이 아니면 해가 없다.
- 그래서 TV 반지름으로 δ 를 맞추면 보험료가 과해진다. 보정은 피해 기준이어야 한다.

## 8. 종합: 인샘플 결정이 갈리는 기제와 OOS 에서 의미가 있는 조건 (2026-11-11 저녁)

### 8.1 네 모형의 식 (결정 x 고정)

| 모형 | V_M(x) |
|---|---|
| N | q·x + CVaR^{q̂}[φ(x, h(q̂))] |
| D | q·x + ρ_TV[φ(x, h(q̂))] (같은 손실 벡터, 깊은 꼬리 가중) |
| C0 | V_N(x) + Π₀(x), Π₀ = 진짜 q̂ 고정, belief TV ≤ δ* 안 최악 예약 피해 |
| C | V_D(x) + Π(x), Π = V_C − V_D |

진짜 OOS 비용은 J(x) = T(x) + H(x) 로 나눈다. T 는 follower 표본을 평균한 진짜 비용, H 는 follower belief 잡음에 따른 흔들림이다.

### 8.2 인샘플에서 결정이 갈리는 기제 (식 + 확정 로그)

- **결정 규칙 (항등식):** M ≠ 기준 ⇔ 기준 격차 < 벌점 차.
- **벌점의 원천:**
  - 경합 시장이 없으면 Π = 0 이다 (H1, 다섯 지리 모두).
  - 벌점은 거점 단위로 생긴다. 예약이 내부해이면서 경합 시장에서 파는 B 거점이 있어야 한다. 지리 전체의 경합 비율로는 예측되지 않는다 (H2 기각).
- **C 가 D 를 떠날 때 고르는 결정 (`ana_pen.py`, 42 시드):** Π(C) 는 거의 0 이다 (중앙 7·0). Π(D1) 중앙은 49·39 다. 즉 C 는 D 기준 근접 후보 중 belief 에 둔감한 결정으로 간다.
- **C0 는 거의 N 을 떠나지 않는다 (다른 세션, 14 시드 중 13 건 C0 = N):** Π₀(N1) 는 중앙 47 로 작지 않지만, 근접 후보와의 N 격차가 대부분 더 크다.

### 8.3 갈린 x 가 OOS 에서 의미 있는 조건

**OOS 분해** (`ana_oos.py`, 재표본 파일럿에서 갈린 21 사례, ρ = 0, follower 뽑기 10 번):
- belief 잡음의 퍼짐 (최댓값 − 평균) 은 중앙 N 32, D 33, C 33 이다. 모형 사이에 차이가 거의 없고 크기도 작다 (비용의 약 1.5%).
- 반면 서로 다른 결정 사이의 진짜 격차는 대부분 120~190 (약 6%) 이다.
- 따라서 OOS 차이는 거의 전부 T 의 차이 (어떤 결정을 골랐나) 에서 나온다. H 의 차이는 작다.

**C 가 D 를 떠난 10 사례의 격차 비교** (`ana_oos.py` 보조 계산):

| 유형 | 사례 | V_D 격차 | V_N 격차 | 진짜 격차 | OOS (C − D) |
|---|---|---|---|---|---|
| 같은 개수 안 교체 ({9;10} → {8;10}) | g72 s1·s5·s8 (ε 0.3) | 16~62 | 31~49 | **−8** (C 가 약간 나음) | −8, +7, −12 |
| 거점 줄이기 ({9;10;11}→{8;10}, {5;9;12}→{5;9}) | 6 건 | 25~104 | 52~393 | **+120~141** | +101~+196 |
| 다른 교체 ({1;5;9}→{9;10;12}) | g89 s3 (ε 0.2) | 72 | 17 | +142 | +146 |

- V_D 는 거점 수가 달라지는 결정들 사이의 진짜 격차 (약 6%) 를 크게 줄여 보인다. 깊은 꼬리 가중은 수요가 낮은 시나리오만 보는데, 거기서는 셋째 거점의 가치가 거의 없기 때문이다 (4.2 절). 그래서 V_D 의 근접 동률은 진짜 근접 동률이 아니다.
- C 의 belief 벌점은 이 가짜 근접 동률에서 결정을 거점 줄이기 쪽으로 넘긴다. 그러면 OOS 에서 6% 를 잃는다.
- 같은 개수 안 교체는 진짜로도 근접 동률이라 손해가 없고, 약간 이기기도 한다.

**C 가 N 을 이긴 사례는 3 건뿐이다** (g89 s1 ε 0.3·0.2, s7 ε 0.2). 모두 C = D = {5;9;12} (진짜 1 위) 이고 N = {1;5;9} 다. belief 헤징이 아니라 데이터 헤징의 교정이 N 의 오류 방향과 맞은 경우다.

### 8.4 현행 OOS 로 C 가 N·D 보다 좋게 나올 수 있나

- **평균:** 4.2 절에 따라 같은 분포에서는 D 쪽이 체계적으로 불리하다. belief 쪽은 H 의 평균이 거의 0 이다 (δ 진단: 실제 belief 평균 피해 ≈ 0). 이득을 낼 경로가 없다.
- **follower 꼬리 (q90·최댓값):** C0 꼬리 시험에서 C vs N 은 평균 −5.4%, q90 −5.4%, 최댓값 −4.9% 로 평균과 거의 같다. 꼬리를 봐도 T 차이가 지배한다.
- **결론:** 현행 OOS 에서 C 가 우위를 갖는 조건은 "C 의 결정이 진짜로 N 이상 (T(x_C) ≤ T(x_N))" 인 경우뿐이다. 이는 belief 헤징이 아니라 데이터 헤징의 우연한 교정으로만 관찰됐다.

### 8.5 구조적 한계와 exploit 할 수 있는 것

**한계 (식에서 나오고 자료로 확인한 것):**
1. **결정 공간이 거칠다.** 서로 다른 결정 사이의 진짜 격차 (약 6%) 가 belief 잡음의 퍼짐 (약 1.5%) 보다 몇 배 크다.
2. **리더 손실이 수요에 단조다** (A 용량이 묶이지 않음). 데이터 헤징의 적대자는 저수요 한 방향으로만 가고, 그 결과 V_D 가 거점 수 사이의 격차를 가짜로 줄인다.
3. **belief 경로가 좁다.** 예약 내부해 + 경합 판매인 B 거점에서만 생기고, 실제 belief 잡음의 평균 효과는 거의 0 이다.
4. **TV 볼은 학습 시나리오 10 개의 가중치만 바꾼다.**

**exploit 할 수 있는 것 (자료에 근거가 있는 것만):**
- **같은 개수 안 교체:** 거점 수를 유지한 채 노출된 거점을 belief 에 둔감한 거점으로 바꾸는 경우다. 진짜 격차가 작아 (g72 에서 −8) 비용 없이 belief 노출을 줄인다.
- **N 기준 근접 동률 사이의 선택:** C0 처럼 데이터 헤징 없이 belief 헤징만 하면 근접 동률은 일치 추정량 V_N 위에서 정해지므로, 가짜 동률 문제가 없다. g72 s5 의 C0 교체 ({9;10} → {8;10}) 는 진짜 손해 6.9% → 6.5% 로 오히려 개선이었다.
- **아직 확인하지 않은 것 (가설):**
  - N 의 다중 최적 (지리의 약 절반에서 관찰) 사이에서 belief 노출이 다르고, C0 (작은 δ) 가 그중 노출이 작은 쪽을 고르면, T 손해 없이 H 의 꼬리를 줄일 수 있다.
  - 효과의 크기는 퍼짐 차이 (사례에서 최대 수십, 예: g72 s10 의 29.8 대 16.3, g89 s3 의 37.7 대 22.2) 로 제한된다.

### 9.6 6 차: 부트스트랩 belief 집합 (지리 30 개 × 시드 10 개)

**질문:** 인샘플 belief 벌점이 진짜 노출을 못 맞히는 이유가 TV 볼의 모양인가, 표본 10 개의 정보 한계인가.

**방법** (`geo/c0b.jl`):
- 후보 x 마다 follower 표본을 흉내 낸 belief 200 개 (리더 시나리오 10 개에서 N_F = 10 개 복원추출한 경험분포) 아래의 피해 Δ(x, d_b) = V(x; q̂, d_b) − V_N(x) 를 계산한다.
- 진짜 값은 follower 40 번 뽑기 (`ot_cfk_g*.csv`) 로 정밀화했다. 진짜 노출 = q90 − 평균.

**결과 1. 노출 추정은 정보 한계다 (H7 기각).**

| 인샘플 추정량 | 진짜 노출과의 순위 상관 (시드 299 개) |
|---|---|
| TV 볼 벌점 | +0.18 ± 0.03 |
| 부트스트랩 q90 피해 | +0.20 ± 0.03 |
| 부트스트랩 최대 피해 | +0.17 ± 0.03 |
| 부트스트랩 평균 피해 | −0.02 ± 0.03 |

- 실제 follower 잡음과 같은 방식으로 만든 추정량도 TV 벌점과 같은 수준이다.
- 식으로 보면: 소매상의 1 단계 최적 조건 f = E^{p̃}[ϖ_i(ξ)] 에서 h_i 는 사용량의 (1 − f/p) 분위다. 노출은 "그 분위가 표본에 따라 얼마나 흔들리나" 인데, 시나리오 10 개에는 0.75 분위 근처의 값이 두세 개뿐이라 이 흔들림을 추정할 수 없다.

**결과 2. 사후 발견: 평균 피해를 더하면 진짜 평균의 순위 예측이 좋아진다.**

| 기준 | 진짜 평균 T 와의 순위 상관 | 후보 중 진짜 최선 선택 |
|---|---|---|
| V_N | +0.53 | 0.40 |
| V_N + 부트스트랩 평균 피해 | +0.62 | 0.52 |

- 규칙 argmin V_N + 평균 피해 로 바꾼 110 건 중 진짜 평균 개선 41 / 악화 12 다. 전체 시드 평균으로 N 대비 −0.135%p ± 0.052 다 (진짜 값 follower 10 번 기준).
- 부트스트랩 평균 피해의 크기는 비용 대비 표준편차 0.84% 이고 부호가 양쪽이다 (5%·95% 분위 −1.2%·+1.4%). 벌점이 아니라 결정마다 다른 편향 보정이다.
- 식으로 보면: 진짜 비용은 T(x) = q·x + E_{p̃}[CVaR^{P*}[φ(x, h(p̃))]] 인데 (p̃ = follower 자기 표본의 경험분포), N 은 p̃ 자리에 q̂ 를 대입한다. h 는 분위와 한도 때문에 p̃ 에 비선형이라 E[φ(h(p̃))] ≠ φ(h(q̂)) 이고, 그 차는 어느 점포의 예약이 내부해인지에 달려 결정마다 다르다.
- 사례 (g48 s3, `geo/why_boot.jl`):
  - 한도에 붙은 B 거점의 예약은 거의 안 움직인다.
  - 내부해인 B 거점의 예약은 44% 에서 내려가 B 판매가 준다.
  - A 점포의 예약은 57~84% 에서 내려가 B 에 유리하다.
  - 그래서 {6;7;12} 는 저수요 B 판매가 651 → 648 로 줄고, {8;10;12} 는 651 → 655 로 는다.
- **주의:** 규칙 네 개를 본 뒤에 찾은 것이다. 쓰지 않은 지리 70 개에서 이 규칙만 판정하는 확인 실험 (9 차) 의 결과는 9.9 절에 적는다.

### 9.7 8 차: 유한 belief 집합 결합 모형 Ch 로 네 칸 비교

**방법** (`geo/ch.jl`):
- V_Ch(x) = q·x + max_{d ∈ 𝔅(x)} max_a CVaR^a[φ(x, h(d))].
  - a 는 확정판 C 와 같은 집합 (TV(a, q̂) ≤ 0.3, 상자, TV(a, d) ≤ 0.1) 위에서 LP 로 푼다.
  - d 는 유한 belief 점 약 360 개 + Data-DR 최악 진짜 방향 + 국소 탐색 3 회.
- witness 형 하한이라 진짜 V_C 이하다.
- 검증:
  - g72 s1 의 확정값과 값 오차 1% 이내다.
  - 파일럿 20 시드에서 확정된 16 건은 결정이 모두 일치하고, overlap 4 건은 best-witness 규칙과 같은 결정이다.

**결과 (지리 20 개 × 시드 5 개, 진짜 값 follower 10 번):**

| 모형 | 데이터 헤징 | belief 헤징 | 진짜 평균 손해 | 꼬리 손해 | 준수율 | 인증값 − 진짜 |
|---|---|---|---|---|---|---|

## 10. 종합: 어디서 안 되고, 왜 그런가, 어떻게 논의할 것인가 (2026-11-12 아침)

기준 설정은 S = 10, p = 800, f/p = 0.25, 예약 한도 300, β = 0.4, follower 표본 10 개다. 지리 100 개 × 시드 10 개를 진짜 F 로 평가했다.

### 10.1 네 모형의 성적

| 모형 | 식 | 진짜 평균 손해 | 준수율 |
|---|---|---|---|
| N | q·x + CVaR^{q̂}[φ(x, h(q̂))] | 0.84% | 0.52 |
| C0 (belief 만, δ* 보정) | V_N + max_{d ∈ 𝔅(δ*)} 예약 피해 | 0.89% | 0.57 |
| D (데이터만, ε̂ 0.3) | max_{a} CVaR^a[φ(x, h(q̂))] | 2.69% | 0.83 |
| C (둘 다) | max_{(a,d) ∈ 𝒟_δ} CVaR^a[φ(x, h(d))] | 약 2.8% (지리 20 개) | 0.80 |
| N + belief 평균 보정 | q·x + E_b CVaR^{q̂}[φ(x, h(d_b))] | **0.64%** | — |

### 10.2 왜 최악 경우 헤징이 OOS 에서 이기지 못하는가 (식 → 자료)

1. **데이터 헤징 (ε̂).**
   - (loc-φ) 에서 φ = −v × (B 판매) 는 수요에 단조다. 그래서 max_a 는 늘 저수요 시나리오에 질량을 몰고 (가중 (0.29, 0.21, 0.10)/0.6), 고수요에서만 가치가 생기는 거점을 빼는 쪽으로 결정을 민다.
   - 자료: D 는 100 개 지리 중 69 개에서 N 보다 나쁘고, 시드 간 최악도 8.2% 대 3.3% 다. p 를 바꿔도 같다 (9.8 절).
   - 보험료의 크기: N 의 결정에서 V_D − V_N 은 비용의 18.7% 인데, N 의 실제 낙관 폭은 3.2% 다.

2. **belief 헤징 (ε̃, δ) 의 최악 경우.**
   - 소매상의 1 단계 최적 조건에서 h_i 는 사용량의 (1 − f/p) 분위다. 벌점은 예약이 내부해이고 경합 시장에서 파는 B 거점에서만 생긴다.
   - 그 크기는 0.75 분위 근처 표본 값들의 간격으로 정해지는데, 시나리오 10 개로는 이 간격이 진짜 follower 의 흔들림을 예측하지 못한다 (순위 상관 +0.18).
   - 실제 follower 잡음과 같은 방식의 부트스트랩 추정량도 +0.20 이다. 그래서 이것은 집합의 모양 문제가 아니라 정보 한계다.
   - 근접 최적 결정 사이의 진짜 노출 차는 중앙 0.69% 뿐이다.
   - 자료: C0 는 시드의 40% 에서 결정을 바꾸지만 진짜 평균·꼬리는 N 과 동률이다.

3. **결합 (C).**
   - V_C − V_N = (V_D − V_N) + Π 에서 앞 항이 18.7%, 뒤 항이 1.9% 다. C 의 결정은 63% 가 D 와 같다.
   - D 와 다를 때는 belief 벌점이 노출된 거점을 빼는 쪽으로 넘어간다. 진짜 평균은 D 와 동률이다 (+0.17%p).

### 10.3 원고의 전제는 성립한다

- 원고의 전제는 "follower 가 리더의 추정을 공유한다고 가정하면 리더가 오도된다" 이다.
- 입지 문제에서 이 전제는 자료로 확인된다. T(x) = q·x + E_{p̃}[CVaR^{P*}[φ(x, h(p̃))]] 에서 N 은 p̃ = q̂ 를 대입하는데, h 가 분위·한도라 비선형이어서 결정마다 다른 편향 (표준편차 0.84%, 부호 양쪽) 이 생긴다.
- 이 편향을 보정하면 진짜 평균이 0.84% → 0.64% 로 준다 (확인 지리 70 개에서 −0.23%p ± 0.04). follower 가 리더 표본을 공유하는 세계에서는 그 이득이 사라진다 (9.9 절).
- 다만 효과가 나는 처방은 최악 경우 (sup over 𝒟) 가 아니라 평균 (데이터로 만든 belief 분포 위의 기댓값) 이다. belief 쪽을 보수적으로 볼수록 이득이 준다 (평균 −0.20, q90 −0.06, 최댓값·TV 최악 ≈ 0).

### 10.4 논의 방향 (제안)

- **입지 실험의 역할:** 계산 성능과 구조 (유한 타입, x 무관 폴리토프) 를 보이는 자리로 둔다. 가치는 두 가지로 정직하게 쓴다.
  - 인증값의 신뢰도: 준수율 0.52 → 0.80.
  - 인샘플 가격·보호 (9.4 절): 명목 가격 0.7% 로 최악 경우 보호 1.1%.
- **OOS 평균 우위는 주장하지 않는다.** 대신 이유를 구조로 설명한다.
  - 리더 손실이 수요에 단조라 데이터 헤징이 한 방향으로만 작동한다.
  - 소매상의 belief 오차는 적대적이지 않은 표본 잡음이다. 그 1 차 효과는 최악 경우가 아니라 결정마다 다른 평균 이동이다.
- **zero-sum 과의 대비:** 원고의 OOS 가치 주장은 네트워크 차단 쪽에 둔다. 입지는 "belief 오차가 온건한 잡음일 때는 최악 경우 헤징이 과보험이 된다" 는 경계 사례로 쓸 수 있다.
- **확장 (모형 변경이라 사용자 결정 필요):** belief 를 데이터로 만든 분포 (재표집한 경험분포들) 로 두고 그 위의 기댓값이나 약한 위험척도를 쓰는 변형이다. 유한 타입 구조 (Theorem game-theoretic) 와 같은 반응 집합을 쓰므로 알고리즘 일부를 재사용할 가능성이 있다. 결론 절의 future work 로 한두 문장 넣거나, 별도 실험으로 발전시킬 수 있다.
