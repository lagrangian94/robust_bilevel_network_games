# belief 블록 CCG 의 lazy cut: "한 나무" 판이 열거였다는 발견과 cut 강화 시도 (2026-11-21 밤 ~ 11-22)

자세한 수치·스크립트는 `docs/nz_belief_block_ccg.md` 11~15 절. 이 문서는 흐름과 결론만 모은다.

## 0. 문제와 설정

- 비제로섬 입지 게임 (loc_tkp, 원고 6.1): 리더 (B 소유자) 가 후보 13 곳 × 크기 3 단계 (200·300·400) 중 최대 3 곳을 연다.
  x ∈ X ⊂ {0,1}^39, |X| = 8,464. 소매상 (follower) 은 A·B 에 약정 h (모든 시나리오 공통) 와 시나리오별 추가 구매를 정하는 2 단계 LP.
  리더 목적 = 출점비 qᵀx + 최악 (분포, belief) 의 CVaR 손실 V*(x). Coupled-DR r = 0.2, S = 10.
- belief 블록 (원고 6 절): belief b = (p, ν, p̃) 를 고정하면 V*(x) 의 하한
  L_b(x) = min_plan { C_L + μ (C_F − η C_L⁺ − V_F^η(x)) }  (plan 사본 + follower 쌍대 + McCormick, 정수 x 에서 정확).
  x 를 고정하면 LP: L_b(x) = min { c_bᵀ z : A_b z ≥ e_b + B_b x }, x 는 우변에만.
- 명시 판 CCG: 마스터에 블록 사본을 belief 마다 넣음 → (x, t0) 만 블록들을 잇는 블록 대각 구조. 블록 추가마다 마스터를 처음부터.
  지리 1 전체 X 7,690 s (VUB 켬) / 7,200 s 한도 초과 (끔).

## 1. 한 나무 판 (블록 = cut 생성기)

- 블록마다 LP 생성기 (x 를 고정 등식으로). x̄ 에서 값 v_b(x̄) 와 고정 등식 쌍대 g_b 로 cut t0 ≥ v_b(x̄) + g_bᵀ(x − x̄) (블록 LP 값은 x 에 볼록 → 전역 유효, 정수 x̄ 에서 정확).
- Gurobi lazy callback: 정수 후보마다 생성기 전부를 풀어 위반 cut; 위반 없으면 싼 belief 탐색, 새 belief 는 나무 안에서 생성기로. 나무 밖에서 α-B&B oracle.
- 엄밀한 single-tree 는 아님: (i) 나무 안에서 belief 가 늘면 incumbent 값이 옛 블록 기준이라 다시 풂, (ii) oracle 이 belief 를 주면 다시 풂.
- 결과: 지리 1 전체 X 2,246 s → 콜백 cut 을 Gurobi Lazy=3 속성으로 옮기자 1,465 s. 지리 15 개 (시드 1): Optimal 14, TimeLimit 1 (지리 5, oracle 병목).

## 2. 발견: 마스터가 X 를 열거하고 있었다

- 첫 나무의 정수 후보 (lazy callback 호출): 8,510 번, **서로 다른 x = 8,464 = |X|**. 모든 지리에서 첫 나무 후보 ≈ |X|.
- 명시 판도 노드 2~3 |X| 였음 → 열거는 lazy 판 고유 문제가 아니라 블록 완화의 성질. lazy 판은 같은 열거를 더 가벼운 LP 로 했을 뿐 (그래서 5 배 빠름).
- 원인 (식): 블록 LP 값 ℓ_b(x) 는 [0,1]ⁿ 에서 볼록이고 정수점에서 L_b (약 −3,000) 이지만, 분수 x 에서 깊이 꺼진다
  (거점을 부분적으로 열면 plan 은 부분 용량으로 리더 수입을 만드는데 쌍대 McCormick 은 그 용량을 쳐주지 않음; 루트 −8.4e6, 블록 약쌍대 켜도 −5,150).
  정수 꼭짓점의 접평면은 이 꺼짐 아래로 지나야 해서 매우 가파르고, 다른 정수점에서 평균 1.4e7 (wd 끔) 아래. **LP cut 하나가 버리는 x: 0 ~ 1 개.**

## 3. cut 을 넓게 만들기 위한 시도 (지표: cut 하나가 버리는 x 수 = qᵀx + cut(x) ≥ 블록 하나의 최적값)

| 시도 | 결과 | 판정 |
|---|---|---|
| 블록 약쌍대 (wd) | 루트 −8.4e6 → −5,150, 나무 재풀이 사라짐, 생성기 LP 2 배 무거움, 후보 수 그대로 | 효과 작음 |
| MW (Magnanti–Wong, 섭동 x̄ + ε(x⁰ − x̄)) | 쌍대 퇴화는 있음 (기울기 차 7e5). x̄ 에서 정확한 MW 는 기본보다 10~20% 강할 뿐, 전체 X 에서 후보 수 그대로, 2 배 느림 | 실패 |
| interdiction (단조성) cut (Fischetti–Ljubić–Monaci–Sinnl 2019) | 블록은 plan 의 최소화라 하한 cut 은 x 무관 쌍대에서 → LP cut 과 같음 | 새 것 없음 |
| 최선의 아핀 (Lagrangian 의 한계) | 버림 576 ~ 988 / 1,156 (후보지 7 곳), 분리 MILP 70~80 번 | 강하지만 비쌈 |
| 최선의 거점 쌍 곱 cut a + gᵀx + Σ H_ij x_i x_j | 버림 1,136 ~ 1,147 / 1,156, 분리 450~480 번 (|X| 의 40%, 계수 211 개) | 사실상 열거 |
| 쌍 곱, 표본에 맞춘 뒤 절편 이동 | 과적합 (절편 7,000 ~ 6e5 이동) | 실패 |
| **사슬 submodular cut** (Nemhauser–Wolsey 부분집합 사슬 꼴, 아래 4 절) | 아래 | 가장 유망 |

## 4. 사슬 submodular cut

S ∈ X 에서 T ∈ X 로 갈 때 S∩T 를 거쳐 (S 의 원소를 빼고 → T 의 원소를 더함) 중간 집합은 모두 S 나 T 의 부분집합 (X 는 down-closed) 이므로

  L(T) ≥ L(S) − Σ_{j∈S∖T} ρ̄_j(S) + Σ_{j∈T∖S} ρ_j^min,
  ρ̄_j(S) = max_{U⊆S, j∈U} [L(U) − L(U−j)]  (S 의 부분집합만, 정확),   ρ_j^min = min_{V∈X, V+j∈X} [L(V+j) − L(V)].

cut: t0 ≥ L(S) − Σ_{j∈S} ρ̄_j(S)(1 − x_j) + Σ_{j∉S} ρ_j^min x_j — **초모듈성·단조성 없이 정의만으로 유효.** (블록 값은 정수점에서 정확하므로 L = L_b.)

- 처음엔 ρ_j^min 대신 ρ_j(∅) = L({j}) − L(∅) 를 썼다 (지리 1 에서 측정상 ρ_j^min = ρ_j(∅)). cut 묶음 (S = ∅ 와 원소 쌍) 은 블록 LP O(n²) 번.
  - 지리 1 후보지 7 곳: 묶음 211 개가 X 의 72% 를 버림. 한 나무 판에 넣자 정수 후보 1,156 → 483, 루트 −1e7 → −3,314.
  - 지리 1 전체 X: 후보 8,464 → 2,044, 노드 24,519 → 5,878, 나무 1 개, **1,465 s → 753 s**.
- **그러나 ρ_j^min = ρ_j(∅) 조건 (첫 원소의 이득이 가장 큼) 은 일반적으로 거짓**: 지리 15 × belief 3 × μ (10, 1,000) = 90 조합 중 82 에서 위반,
  크기 대부분 −15 ~ −90, 지리 5 에서 −410, |V| = 1 에서도 위반 (거점 보완). 지리 1 은 위반 0 이라 결과가 맞았을 뿐이고 인증은 아님.
  해석: 조건은 소매상 선택의 대체재 성질에서 나온다. 1 단계 수송이면 M♮-오목성으로 성립하지만, 약정 h 가 시나리오들에 공유되고 (M♮ 은 합에 닫혀 있지 않음)
  follower 최적성·비관 동률·유한 μ 가 들어가 깨진다.
- **정확한 ρ_j^min 을 쓰면 (열거로 구해 진단)**: 전체 X, cut 묶음 703 개, 무효 0, 버림 지리 1 85%, 2·5·15 99.8~99.9%, 10 96.7%.
  → cut 의 세기는 남아 있다. 남은 문제는 ρ_j^min 을 열거 없이 구하는 것.

## 5. ρ_j^min 을 MILP 로

min_V [L(V+j) − L(V)]: L(V+j) 는 블록 primal 사본 (x + e_j), −L(V) = min_w [−D(w, x_V)] 는 블록 LP 쌍대 (`lp_matrix_data` 로 일반 구성).
x 는 쌍대 목적에 고정 등식 쌍대 φ_i 와의 곱 x_i φ_i 로만 들어가 indicator 로 정확 (big-M 없음).

- 지리 5, 원소 6 개: MILP 값 = 열거 값 (6/6), 원소당 2.4~2.9 s (10 스레드), **노드 1,261 (매번 같음 ≈ V 후보 약 630 개의 2 배)**.
  → MILP 도 V 를 사실상 열거. belief 하나에 원소 39 개 ≈ 105 s, X 전체 열거 (109 s) 와 비슷. V 공간은 |X| / n 차수.
- 최악의 V 는 모두 원소 30 을 포함 (특정 거점의 보완 관계).

## 6. 현재 판단과 열린 질문

1. 사슬 cut 은 이 계열에서 처음으로 마스터의 열거를 깬 cut 이다. 유효성은 ρ_j^min (또는 그 하한) 에만 달려 있다.
2. ρ_j^min 을 싸게 (하한으로라도) 구하는 방법이 없으면, 원고에서 "열거 없이 일반화되는 방법" 이라고 말할 수 없다.
3. 후보: MILP 의 dual bound 를 일찍 쓰기 (완화가 약해 느슨할 것), 쌍대 구조에서 해석적 하한, 모든 j 를 한 MILP 에서 (가장 크게 어기는 (V, j) 만 고치는 반복),
   구조 (보완 거점) 이용, 혹은 문제를 바꿔 (모형·정식화) 대체재 성질이 성립하게.
4. 별개로 α-B&B (oracle) 병목: 지리 5 의 상한은 follower belief × 반응의 곱 (α·d) 의 McCormick 이 띄운다 (곱을 정확히 하면 상한이 incumbent 아래로).
   후보: 노드별 belief 범위 조이기 (OBBT).

## 7. 함께 확인된 사실 (부수)

- 증폭: CCG 허용오차 0.5% 는 총목적 (≈ 1,300) 기준이고 oracle 값 (≈ 3,150) 은 출점비로 상쇄되어, oracle 에 필요한 상대 정밀도는 ≈ 0.19%.
- Stalled 2 건 (지리 8, 13): oracle 이 t0 보다 큰 하한을 증명했는데 α 정확 평가가 실패 → 그 하한으로 no-good (λᵁ ≥ λ̄ 가정 아래 유효) 을 넣어 해결.
- λᵁ 를 100 → 10 으로 바꿔도 oracle 상한 궤적은 같음 (λᵁ 가설 기각).

## 8. 외부 검토 (MIP 전문가 역할 에이전트, 2026-11-22) 의 요지

- 사슬 cut 유효성 논증은 맞음 (telescoping; down-closed 는 ρ^min 정의역이 경로의 문맥을 덮는 데만 필요; 정의역은 X 의 down-closure 로 적을 것).
- 정확한 ρ_j^min 은 삼중 집합 (7,722 = X 의 91%) 의 L 을 요구 → "정확한 ρ^min 이면 85~99.9% 버림" 은 열거 뒤에 cut 을 만든 것이라 방법의 근거가 못 됨.
- 사슬 cut 은 x 에 아핀 → 최선의 아핀 (볼록 포락, Lagrangian 한계) 보다 강할 수 없음. 묶음의 "버림 수" 지표는 분수점에서 과대 (지리 1: 85% 버림인데 루트 LP −3,393, 최종 LB −1,633).
- 명시 판 노드 2,311 = 2·1,156 − 1 (완전 이진 나무: LP 가 한 번도 가지를 못 침), ρ^min MILP 노드 1,261 ≈ 2·630 도 같은 모양.
- 확인할 숨은 가정: 블록 McCormick 쌍대 상한 U 가 증명된 값인지 (경험값이면 모든 하한이 무효일 수 있음), |X| 표기 (원고 8,463 대 문서 8,464).
- 제안: 기여를 "열거 단위를 oracle (분) 에서 블록 LP (ms) 로" 로 서술, 한계를 둔 열거 (표) 마스터를 기준으로, 실험 E1~E5.

## 9. E1·E2 (지리 1 전체 X, 재실행 726 s 의 최종 belief 11 개, `scratchpad/e12.jl`)

블록 11 개의 정수 최적 z* = −1,629.42 (x = {3:300;10:200;15:300}), CCG LB −1,630.27.

E2 (최적값의 τ 안에 드는 x 의 수, |X| = 8,464):

| τ | 0.5% | 1% | 2% | 5% |
|---|---|---|---|---|
| 명목 블록만 | 10 | 33 | 38 | 52 |
| 최종 블록 11 개 | 10 | 12 | 23 | 57 |

→ 문제는 평탄하지 않다. 나무가 X 를 다 훑는 원인은 하한의 약함이지 근접해가 많아서가 아니다.

E1 (블록별 X 위 볼록 포락의 최대로 만든 conv(X) 위 LP 하한 = 블록별 아핀 cut 의 천장): **z_conv = −1,633.94, z* 와의 간격 0.28%** (허용오차 0.5% 안).
점검: 블록 하나면 z_conv = 정수 최적 (−2,089.40) 으로 같음.

→ 블록마다 볼록 포락을 받치는 아핀 cut 만 있으면 원리상 루트에서 거의 끝난다. 남은 문제는 분리 비용 (그런 cut 을 열거 없이 싸게 얻기).
  후보지 7 곳의 루트 Lagrangian 시험 (10 절 아래 nz_benders_cut_weakness 7 절: 8 라운드 2,697 s, −2,021 에서 정체) 은 천장에 한참 못 미쳤으므로 분리가 수렴하지 못한 것.
한계: 지리 하나·시드 하나, 최종 belief 집합을 안다고 놓은 값.

## 10. 볼록 포락 (Lagrangian) cut 분리 비용 (지리 1 전체 X, belief 11 개, `scratchpad/envsep.jl`)

지금 솔버의 cut 은 LP cut (블록 LP 의 [0,1]ⁿ 볼록 확장 ℓ_b 의 접평면) 이고, 볼록 포락 cut (Ľ_b, X 위 가장 높은 볼록 함수의 접평면) 은 쓰지 않는다.
정수점에서 ℓ_b = Ľ_b = L_b, 그 사이에서 ℓ_b ≤ Ľ_b ≤ L_b.

1. 이상적 분리 (블록 값 표 위 DW LP 의 쌍대로 x̃ 마다 블록별 정확한 포락 cut): 30 라운드 · cut 269 개에 간격 0.33% (허용오차 안),
   37 라운드 · 296 개에 천장 −1,633.94 (0.28%). 라운드 2 86%, 9 6.7%, 15 1.9%, 24 0.99%.
2. cut 하나를 열 생성으로: 가격 문제 29~33 번 (값은 정확한 포락 값과 같음).
3. 가격 MILP (블록 하나 + 이진 x, min L_b(z) − πᵀz): 19~20 s, 노드 약 19,000 (≈ 2.2|X|) → 가격 문제 자체가 X 를 열거.

비용 어림: cut 마다 처음부터 열 생성이면 가격 MILP 약 8,000 번 ≈ 42 시간, 열 재사용으로 cut 마다 1 번이라 해도 약 270 번 ≈ 1.5 시간.
지금 한 나무 판 (사슬 cut 없음) 1,465 s.

결론: 포락 cut 은 루트만으로 허용오차 안에 들 만큼 강하지만, 그 가격 문제가 블록 하나짜리 마스터라 같은 이유 (블록의 x 에 대한 LP 완화 = 높은점 완화의 약함) 로 열거한다.
cut 의 꼴을 바꾸는 접근 (LP cut, MW, 사슬 cut 의 ρ^min, 쌍 곱 cut, Lagrangian cut) 은 모두 이 한 원인에서 막혔다. 남는 지렛대는 블록 완화 자체 (x 에 대한 정식화) 를 강하게 하는 것이다.

## 11. 싼 Lagrangian 계열 시험 (지리 1 전체 X, belief 11 개, `scratchpad/sbcut.jl`, `pricelog.jl`)

가격 MIP (min_{z∈X} L_b(z) − πᵀz, 블록 하나 + 이진 사본) 는 블록 값 표의 최소로 대신하고 횟수만 셈. 루트 LP (x ∈ conv X) 에 라운드마다 블록별 cut.

| 방법 | 가격 MIP 수 | 최종 루트 LP 하한 | 천장 −1,633.94 대비 |
|---|---|---|---|
| 정확한 envelope cut (DW 쌍대, 10 절) | cut ≈ 270 (cut 당 열 생성 ≈ 30) | −1,635 | 0.33% |
| Strengthened Benders (LP 쌍대 기울기 + MIP 로 절편) | 649 (60 라운드) | −6,656,721 | 무효 수준 |
| Lagrangian 쌍대 Kelley K = 3 (π 상자 ±5,000, LP 기울기에서 시작, 안정화 없음) | 946 | −13,350 | 719% |
| K = 5 | 2,805 | −13,350 | 719% |
| K = 10 | 5,909 | −12,990 | 697% |

- SB 는 LP 기울기가 너무 가팔라 절편을 올려도 쓸모 없음.

## 16. 값함수 cut 시험 (지리 1 전체 X, 블록 1 명목, π = 0, `scratchpad/vfcut.jl`)

**cut.** f^η(plan) ≥ a + bᵀz, a = min_{t∈X} φ(t) − bᵀt (oracle). 정수 z 에서 plan 은 follower 최적이라 f^η = φ(z) ≥ a + bᵀz → 유효.
π 와 무관해 같은 블록의 모든 가격 MIP 와 CCG 마스터에 재사용 가능. 분리: z̃ 에서 max a + bᵀz̃ (a + bᵀt ≤ φ(t), t ∈ T) 를 열 생성, 열은 oracle 해.
oracle 은 follower 쌍대 최소 + 쌍대×t McCormick 의 min–min MILP (zero-sum 차단 꼴). 절편은 oracle 의 하한이라 중간에 멈춰도 유효.

**결과.**
- oracle 은 싸다: 43 회 16 s (평균 0.37 s, 노드 68 개). 같은 39 이진인데 최적성 제약이 없는 min–min 은 쉽다.
- 루트 5 라운드 (cut 4 개, 17 s) 로 plan 의 f^η 가 −1,573,914 → −1,272,855 (= φ̌(z̃), 수렴) 까지 올라갔지만 **루트 값은 −8,000 그대로**.
- 이상적 판 (X 전체의 볼록 결합 λ + SD) 의 루트도 **−8,000**. 13 거점에 퍼진 z̃ 에서는 φ̌(z̃) 자체가 낮아 (여러 배치의 섞임) plan 이 φ̌ 를 맞추면서 B 용량을 다 팔 수 있다.
- cut 넣은 가격 MIP: 노드 15,656 → 13,513, 시간 21.5 → 56.9 s (조밀한 cut 이 노드 LP 를 느리게 함).
- 15 절의 λ 판이 노드를 9 배 줄인 것은 루트가 아니라 분기 뒤의 효과다: z_i 를 고정하면 λ 가 그 부분 X 의 점으로만 남아 포락이 노드마다 저절로 조여진다.
  열거 없이 따라 하려면 노드마다 고정을 반영한 oracle 로 국소 cut 을 분리해야 하는데, 루트 하나에 oracle 43 회 (16 s) 였으므로 가격 MIP 하나 (21 s) 보다 비싸다.
→ 값함수 cut 은 가격 MIP 를 빠르게 하지 못한다. 약함은 "follower 최적값을 모름" 이 아니라 "분수 z 에서 plan·φ 가 서로 다른 배치를 섞음" 이다.

## 17. 원고 사슬 재검토와 두 정식화 시험 (지리 1 전체 X, 블록 1 명목, π = 0, `scratchpad/siteflift.jl`, `swapvi.jl`)

**원고 사슬에서 나오는 판의 판정.** follower 최적성을 f^η(plan) ≥ g(z) (g 볼록) 한 줄로 거는 판 (벌점, SD, 약쌍대, 값함수 cut, Lagrangian) 은
g ≤ φ̌ (정수점 φ 의 볼록 포락) 라 루트가 이상적 VF 판 (−8,000) 이상이 될 수 없다. KKT 의 LP 완화는 HPP. Lemma phi 꼴 (θ 로 recourse 비관값을 min LP 로)
과 Ω_b (belief 고정 minimax) 는 r = b_x + Bh 때문에 h·π 곱이 생겨 정수 x 에서 정확하지 않거나 (t0 ≥ max 꼴) h 고정 cut 이 되어 국소적이다.
→ −8,000 을 넘으려면 plan 의 성분을 z 와 직접 묶어야 한다.

**(a) 거점 묶음 lifting (perspective, SA-1 꼴).** 거점마다 plan·쌍대를 열림 사본 (척도 o_i) 과 닫힘 사본 (척도 1 − o_i) 으로 나누고,
w_ij = z_j o_i 의 RLT (McCormick, 카드 제약 곱, 대칭) 를 넣음. 변수 5,684 → 152,922.
- 루트 LP −8,000 (그대로, 28.5 s). 다른 거점이 분수로 남아 각 사본 안에서 섞임이 그대로.
- 가격 MIP: 600 s 에 루트 노드도 못 끝냄 (incumbent −2,753, 하한 −8,000).

**(b) 교환 부등식 (이 입지 문제 전용).** 약정 h_i < min(w_i, cap_i) 이면 약정을 ε 늘려 추가분을 약정 출하로 바꾸는 것이 follower 에 이득이므로
최적에서 P̃(spot_is > 0) ≤ κ = (f + η v)/p = 0.7506. 그래서
  Σ_s d_s spot_is ≤ κ (cap_i(z) − h_i) + (1 − κ)(b_max − w_i) h_i / w_i   (B 거점마다, h_i = w_i 와 h_i = cap_i 경우 포함)
- 정수점 8,464 개 전부에서 블록 값 불변 (최대 차 1.6e-2, 상대 1e-4 기준 불일치 0) → 수치로 유효 확인.
- 루트 LP −8,000 → **−6,500** (간격 80% → 46%). lifting 을 더해도 −6,500.
- 가격 MIP: 노드 15,656 → 12,120, 시간 21.5 → 25.3 s.
→ 루트는 오르지만 노드는 23% 만 줄어든다. 거점 사이의 섞임 (13 거점에 퍼진 z̃ 로 B 를 다 팖) 은 남는다.

## 18. 문헌 대조: Byeon–Van Hentenryck hybrid cut, Ralphs 그룹 (조사 에이전트 두 개, 2026-11-22)

**Byeon–Van Hentenryck (arXiv 1902.04375 v3, 5 절 식 16~18, HTML 판 5.1 절까지 원문 확인, 8 절 계산 결과는 못 읽음).**
- 식 (18): t ≥ ψ̂₂ᵀ(b − Ax) + û_yᵀ(h_y − G_xy x) − ŵ(dᵀŷ + (M − dᵀŷ) g_x̂(x)), g_x̂ = Hamming 거리, M = HPP 영역에서 follower 목적의 상한.
  표준 cut (14a) 의 McCormick 상한 ψ̄ 항을 no-good 으로 바꾼 것. 동기는 계수 범위 (수치), 강도가 아님. 이진 리더에서만 유효, 비제로섬·optimistic 허용.
- 우리 문제는 가정을 만족하지만, 이웃 정수점 (g = 1) 에서 cut 이 ŵ(M − dᵀŷ) 만큼 떨어짐. M − dᵀŷ 는 follower 값 범위 (φ(0) ≈ −1.76e6 와
  열린 배치 사이, 10⁵~10⁶ follower 단위, 어림) × ŵ → 실제 이웃 차 (~1,500) 보다 훨씬 커서 x̂ 한 점만 자르는 no-good = 우리 안전장치와 같음.

**Ralphs 그룹.** GBD (Bolusani–Ralphs, Math. Program. 2022): 마스터 z ≥ ρ̄(b − Ax), follower 값함수는 primal function (상한) 으로 근사,
연속 follower 에서는 기저가 최적인 영역에서만 유효해 지시 이진 + big-M 으로 영역 전환 (식 34, 39), 계산 결과 없음. MibS (Tahernejad–Ralphs–DeNegre,
MPC 2020): 연결변수 분기 + 고정 뒤 (UB) LP + generalized no-good → 연결변수 값을 사실상 하나씩 방문, HPP·LR 이 "rather weak" 라고 명시.
Valid inequalities (Tahernejad–Ralphs, COR@L 20T-013-R1): 약함의 원인을 d²y ≤ φ(b² − A²x) 완화로 짚음, Benders binary cut (정리 5) 은 단조성으로
x̂ 의 상위 집합 전체에 유효 (우리: 용량 증가 = follower 실행가능 집합 확대 → 전부 L⁺). intersection cut (ISIC/IDIC) 은 follower 정수성 필요 → 해당 없음.
- 우리와의 관계: GBD 의 primal function 과 Benders binary cut 은 모두 "f^η(plan) ≥ (X 위에서 유효한 z 의 볼록·선형 함수)" 꼴이라 17 절 논리로
  루트는 이상적 VF 판 (−8,000) 을 넘지 못한다. 효과는 분기 뒤 노드에서만 (15 절 λ 판의 4~9 배가 상한).
