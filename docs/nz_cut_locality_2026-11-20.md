## 2. 원인

- 닫힌 거점 i 의 cut 계수 ≈ −b_i (θᵁ Σ ν_s σ̂_is + λᵁ Σ p̃_s σ̄_is). σ = follower 가 그 거점 첫 용량에서 아끼는 비용 (거리 단위, 650~2,800 /단위).
- cut 은 Ω 의 한 점이라 follower 반응·쌍대를 x̂ 에 고정한다 (재정식의 귀결: 반응을 벌점 붙은 독립 변수로 바꾸고 x 를 목적계수로 보냄).
- Ω 의 cut 은 상자 전체에서 유효해야 하므로, 분수 x 의 "첫 용량 횡재" 로 가파른 볼록 확장 F̂ 의 받침평면이 될 수밖에 없다 → MW 도 무력.

## 4. 핵심 발견 (2026-11-20 밤)

대리 문제: follower belief = 리더 가중 = q̂ (명목), 낙관적 동률. 전체 x 값 표 `vtable_g1_nominal.tsv`.

1. 한 곳 값 = −5·min(용량, 300) (+ 크기 400 이면 현장 76~91 단위). 총 약정이 600~763 에서 포화 (모든 거점 쌍이 상호작용).
2. 리더 가격 = follower 가격 / 120 (약정 5 = 600/120, 현장 6.67 = 800/120) → 리더 수익 = follower 의 리더 지불 / 120.
3. **μ 벌점 하한**: 모든 μ ≥ 0 에서
   LB_μ(x) = min_y [ μ·cost_F(y) + cost_L(y) ] − μ·V_F(x) ≤ (낙관적) V(x) ≤ 비관적 V(x).
   μ = 1/120 은 지불 상계 (V_F − V_F⁰)/120.

| μ·120 | 하한 느슨함 중앙값 | 남는 x | μ 마스터 MILP (`mumaster.jl`) |
|---|---|---|---|
| 1 | 11.3% | 940 | −2,482.81, 7.5 s |
| 5 | 2.5% | 12 | −2,099.40, 16.7 s |
| 10 | 0.3% | 5 | −2,095.68, 17.7 s |
| 30 | 0.0% | 3 | **−2,095.27 (정확)**, 16.2 s, 노드 18,352 |

4. 원고의 λᵁ = 100 은 이 대리 문제 필요량 (μ ≈ 0.25) 의 약 400 배. cut 기울기와 마스터 횡재가 μ 에 비례하므로, λᵁ 를 정확 벌점 문턱 근처로 줄이는 것이 핵심 레버일 수 있다.
5. 주의: 원고 Ω 는 비관적 (max) 이라 벌점이 작으면 V* 를 **과대** 평가한다 (유효한 하한이 아님). μ 하한은 낙관적 (min) 이라 모든 μ 에서 유효. 비관적 동률은 작은 비용 섭동으로 처리해야 한다 (다음 단계).

## 5. 남은 문제와 다음 단계

- 루트 LP 는 μ 에 비례해 약함 (μ·120 = 30 에서 −197,700), 노드 > |X|.
- 비관적 동률: 낙관적 대리와 비관적 값의 차이, ε 섭동으로 비관적 반응을 유일하게 만드는 방법.
- DRO 확장: belief 블록 여러 개 (follower belief d, 리더 CVaR 가중 r) 의 μ 하한 + belief 생성 + α-B&B 상한.
- 지리 5 는 바깥이 아니라 x* 하나의 상한 증명 (α-B&B 3,336 s 에 2.7%) 이 병목 (L6 와 같은 종류).

→ 동률 처리가 최적 x 를 바꾼다. 섭동으로 비관적 선택을 μ 블록 안에 넣을 수 있다.

### DRO μ 블록 마스터 (`dromu.jl`)

belief 블록 (follower belief d, 리더 CVaR 가중 r) 마다
LB(x) = min_(h,y) [ μ·(C_F − ε C_L) + C_L ] − μ·V_F^ε(x)  (모든 μ ≥ 0 에서 비관적 V* 의 하한).
첫 항은 원문제 사본, V_F^ε 는 쌍대 (x·π 는 McCormick). x̂ 에서 싼 belief 탐색 → 안 오르면 α-B&B.

- **ε 가 중요**: follower 에게 거의 동률인 반응 (비용 차이가 허용오차 수준) 이 있어, ε = 1e-3 이면 μ 를 1,000 으로 키워도 블록이 정확 값 (−2,900.98) 대신 −2,923.13 에 멈춤. ε = 0.1 이면 μ = 10 에서 0.05% 안, μ = 100 에서 정확 (`blockdiag.jl`).
- **DRO 는 μ 가 더 커야 함**: 명목은 μ ≈ 0.25 로 정확, DRO belief (r/d 비율 최대 2.8) 는 μ ≈ 10.
- 작은 예 (후보지 3 곳, |X| = 64, μ = 10, ε = 0.1): **Optimal, x* = {6:300;13:300}, 하한 −1,417.58 / 상한 −1,414.65**, 열거 방식과 일치. 236 s (마스터 23 s, oracle 2 회 204 s, belief 7).
- 지리 1 전체 X (μ = 10, ε = 0.1): 하한 −2,089 → −1,709 → −1,655 → −1,640 (알려진 최적 −1,629.4). 그러나 마스터 시간이 belief 수에 비례해 증가 (1~5 개: 48 · 157 · 296 · 445 · 570 s), 노드는 매번 약 1.95 만. 1 시간 안에 수렴 못 해 중단.
- 코드 실수 기록: 쌍대의 섭동 계수 부호를 반대로 써서 (d·c − ε r ℓ) 하한이 최적을 넘은 적 있음 (2με·리더 비용만큼). 고친 뒤 유효.
- oracle (α-B&B) 이 돌려준 α 가 잡음 때문에 정확 평가 LP 에서 실행불가가 되는 경우가 있어 사영 (`nz_feasible_alpha`) 추가.

### 마스터가 왜 1.95 만 노드를 도는가

- 크기 단계 39 개, 최대 3 곳인 X 의 정수점 8,464 개를 잎으로 하는 분지 나무 전체가 약 1.7 만 노드. 관측된 1.9~2.0 만은 거의 나무 전체 → LP 하한이 잎 전까지 거의 못 쳐냄.
- 루트 강화 시도 (`mtest.jl`): 거점 단위 McCormick 합산, 거점 개방 변수에 분지 우선순위 → 19,867 → 19,278~19,421 노드, 시간 변화 없음.
- 단일 belief 에서 μ 를 줄이면 노드가 줄지만 (μ·120 = 1: 3,745, 5: 14,774, 30: 18,352) 정수점 하한이 느슨해짐 (μ·120 = 1 에서 18.5%).
- 결론: 분수 x 의 횡재가 값 차이보다 크면 크기와 무관하게 가지치기가 안 됨. 정확한 볼록 껍질은 X 전체에 대한 분리 (perspective 를 거점 수 상한 단계까지) 라 X 크기에 비례.

### 지금 위치와 선택지

1. μ 블록 + 섭동은 이론적으로 깔끔하고 (모든 μ 에서 유효, 비관 처리, 원고의 λᵁ 를 정확 문턱 근처로 낮춤) 작은 예에서 검증됨. 원고 알고리즘의 개선점으로 쓸 수 있음 (belief cut 을 선형 cut 대신 블록으로 넣고 λᵁ 를 작게).
2. 하지만 X 가 8,464 이면 마스터의 분지한정이 사실상 X 를 훑는다. 이것을 넘으려면 문제 구조 (거점 사이 대체재 성질의 증명 등) 가 필요하고, 측정상 깔끔한 구조 (supermodular) 는 성립하지 않음.
3. 계산 성능 표는 문헌 규모 (Goyal |X| ≤ 32, 후보지 4~5 곳 × 크기 세 단계면 |X| 수십~백) 로 잡고, 큰 X 의 한계는 원고에 기술하는 쪽이 현실적.

## 5c. 구조 cut (단조성 + 집합 부분가법성) 의 검토 (2026-11-21 새벽)

### 착상
belief b = (d, r) 고정 비관적 리더 비용 V_b(X) (X = 연 (거점, 크기) 원소 집합) 가
(M) 단조 V_b(Y) ≤ V_b(X) (X ⊆ Y) 와 (S) 서로소 부분가법 V_b(T ∪ S) ≥ V_b(T) + V_b(S) 를 만족하면
  t0 ≥ V_b(Ŝ) + Σ_{e∉Ŝ} V_b({e}) x_e
가 모든 정수 x 에서 유효하다 (V(X) ≥ V(X∩Ŝ) + Σ_{e∈X∖Ŝ} V(e) ≥ V(Ŝ) + …). 기울기가 값 크기 (한 곳 값) 라 횡재가 없다.

### 1 단계 모형에서는 증명된다
약정을 시나리오마다 고를 수 있으면 follower 는 시나리오별 최소비용 흐름이고, 원천에서 나가는 거점 호는 서로 대체재다
(Gale–Politof 1981 의 conformal 순환 논법: 연 호를 지나지 않는 순환은 빼도 최적, 남는 순환은 σ 의 다른 호를 역방향으로 지남).
비관적 선택은 ε 섭동 (여전히 최소비용 흐름) 으로 같은 논법이 적용되고, 거점 수입은 거점 총흐름의 증가함수라 (S) 가 거점별로 성립.
무작위 작은 예 847 회: 위반 0 (`toy_subst.jl`, STAGE1=0).

### 원래 모형 (약정 h 가 시나리오 공통) 에서는 깨진다
- 손 반례: 시나리오 둘에 수요가 서로 다른 고객에 몰리고, A 약정 하나를 두 시나리오가 나눠 쓰는 (pooling) 경우.
  a 만, b 만 열면 A 약정이 이겨 수입 0, 둘 다 열면 A 약정이 깨지고 a·b 추가분을 씀 → R(T∪S) = 800 D > R(T) + R(S) = 0.
  같은 경로로 단조성도 깨질 수 있다 (새 거점의 약정이 기존 거점의 추가분을 대체하면 단가가 800 → 600).
- 무작위 작은 예 847 회: 집합 부분가법 위반 8 (최대 6.1%), 거점별 대체재 위반 21.
- 실제 계열 (`msa_check.jl`, belief 명목, 지리 1·2·4·5):

| 지리 | M1 위반 (최대) | S1 V(ab) ≥ V(a)+V(b) 위반 / 702 (최대) | S2 / 600 | S3 / 200 |
|---|---|---|---|---|
| 1 | 1/1,643 (0.4%) | 1 (2e-6) | 0 | 0 |
| 2 | 6/1,643 (0.9%) | 116 (1.8%) | 59 (1.5%) | 5 (1.3%) |
| 4 | 5/1,643 (1.0%) | 8 (0.5%) | 1 (0.3%) | 0 |
| 5 | 15/1,643 (3.9%) | 53 (7.5%) | 37 (8.1%) | 3 (4.4%) |

→ 구조 cut 은 이 계열에서 유효하지 않다 (지리 1 에서 거의 성립한 것은 우연). 정확 알고리즘에 넣지 않는다.
변형 실험 (작은 예 847 회, 2 단계): A 약정만 없애면 위반 7, B 약정만 없애면 11, 둘 다 없애면 0 → 보완 관계의 원인은
어느 쪽이든 시나리오 공통 약정이다.

### μ 블록의 ε 와 μ 의 관계 (`blockdiag0.jl`, x̂ = 거점 7·11 크기 300, DRO belief r/d 최대 2.78)

| 블록 | μ = 0.25 | 1 | 10 | 100 | 정확값 |
|---|---|---|---|---|---|
| ε = 0 (낙관) | −2,986.67 | −2,986.67 | −2,986.67 | −2,986.67 | 낙관 −2,986.67 |
| ε = 0.1 | −2,984.56 | −2,978.25 | −2,902.51 | −2,900.98 | 평가기 −2,900.98 |

- ε = 0 이면 μ = 0.25 (μ·120 = 30) 에서 이미 낙관 값과 같다. 큰 μ 가 필요한 이유는 섭동의 동률 깨기 (필요 μ ≈ 1/ε) 이다.
- 낙관 블록은 모든 μ 에서 엄밀한 하한이다 (낙관 ≤ 비관, ε 선택 불필요). 대신 이 x̂ 에서 낙관과 평가기 비관의 차가 2.9%.
- 허용오차 1e-9 의 엄격한 비관 값은 −2,922.65 로 평가기 (−2,900.98) 와도 다르다. 평가기는 follower 의 거의 동률 (허용오차 안) 을
  동률로 취급하고, ε = 0.1 섭동이 그것을 재현한다. ε 섭동의 정확성은 수치로만 확인했다 (belief 하나, 8,464 점, 0.04% 안).
- 알려진 최적 x* = 점포 {3:300; 10:200; 15:300} 에서 (`blockdiag0_xstar.jl`, r/d 최대 2.95): ε = 0 블록은 μ = 0.25 에서 −3,814.37,
  μ = 10 에서 낙관 정확값 −3,781.06. 평가기 값은 −3,688.21 (리더 항 기준 차 2.5%, 목적 −1,629 기준 5.7%).
  → 낙관 블록만으로는 0.5% 인증이 안 되고, 낙관 블록도 DRO belief 에서는 μ ≈ 10 이 필요하다. 이 길도 닫힘.

### 용량 쌍대 상한 조이기 (`utest.jl`, `dromu3.jl`)
- loc_tkp.jl 머리말 논증 (약정분은 h 로 고정, 용량 한 단위는 추가분 하나만 늘림, A 에 늘 여유) 에 따라
  U′_i = max_j (max_A c_Aj − c_ij)⁺ (기존 gapB 보다 p = 800 작음; 거점 5 는 970 → 170, 13 은 1,200 → 400).

- 그러나 마스터 노드 수는 그대로 (후보지 9 곳: 반복마다 약 5,200 또는 8,300, 기준과 같음). 전체 2,591 s (기준 2,072 s, 반복 10 대 9).
- belief 마다 μ·120 = 30 블록을 1,200 블록과 같이 넣기 (`dromu4.jl`, t0 ≥ max, 모두 유효): 작은 예 Optimal 확인.
  후보지 9 곳에서 노드 5,234 그대로, 마스터 시간 약 2 배 → 4 반복에서 중단. μ·120 = 30 에서도 거점당 횡재가 수만 단위. 루트 LP 하한이 μ 에 비례해
  수백만 단위로 약해 (μ·120 = 30 에서 −197,700, 1,200 이면 그 40 배), 상한을 절반으로 줄여도 잎 근처 전에는 못 쳐낸다.

### 왜 μ ≈ 10 이 필요한가 (근본 원인)
- 적대 belief 에서 follower 는 거의 무차별 (위 표: follower 비용 0.148 = 상대 1.3e-7 차이로 리더 비용 9.6 이동, 비율 ≈ 65).
- 블록이 비관 선택을 재현하려면 μ ≥ (리더 이득 / follower 손실) 이 필요하고, ε 섭동에서는 그 비가 1/ε (= 10).
  엄격한 (허용오차 0) 비관이면 μ ≥ 65 수준.
- follower 비용 규모 (1e6) 와 리더 값 규모 (1e3) 의 차이 × 거의 동률 → 마스터 완화의 분수 x 횡재 = μ × 용량 가치 × 크기 (1e5~1e6).
  이것은 이 인스턴스 계열 (적대 belief 가 follower 를 무차별하게 만듦) 의 성질이라 cut 이나 상한 조이기로는 풀리지 않는다.
