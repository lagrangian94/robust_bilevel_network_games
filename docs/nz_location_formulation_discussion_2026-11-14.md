# 입지 게임 식 확장 논의 (2026-11-13 ~ 14)

원고 `paper/joc-non_zero_sum/INFORMS-IJOC-Template.tex` 6.2 절 (식 loc-Q, loc-φ) 에서 belief 헤징의 가치가 보이지 않아, 식을 어떻게 확장할지 논의한 기록이다. 실험 숫자의 상세는 `docs/nz_location_value_report_2026-11-12.md` 13~14 절에 있다. 저장소 코드와 원고는 고치지 않았고 커밋한 것도 없다.

## 1. 한 줄 결론

- 원고 식 그대로는 belief 헤징 (Belief-only, Coupled) 이 Nominal 을 꼬리에서 −0.3% 정도만 이기고, 리더가 q̂ 를 추정하면 그것도 사라진다.
- 꼬리 우위가 1% 근처까지 커지는 것은 B 의 수입이 예약에서만 나오는 구조 (v^S = 0, 또는 B 만 비예약 판매 금지) 뿐이었다. 둘 다 인위적이라 채택하지 않는다.
- **채택 방향 (2026-11-14 사용자 결정): 약정 물량 방식.** 예약을 확정 주문으로 보고, 남는 물량 s_i 를 소매상의 recourse 변수로 두어 B 가 약정 물량 전부에 대해 마진을 받게 한다. 일반 모형은 바꾸지 않는다.
- **리더가 진짜 분포를 아는 조건에서 약정 방식 (f/p 0.25, κ = 0) 의 꼬리 우위는 −1.82 ± 0.62% 다** (원고 식 −0.26, 쌍별 차 −1.57 ± 0.61). 평균도 손해가 아니다 (−0.33 ± 0.29). 
- **리더가 q̂ 를 추정하는 조건에서도 남는다.** Belief-only (δ = 0.1) − Nominal 이 평균 −1.07 ± 0.36, 꼬리 −1.48 ± 0.52, Coupled − Data-DR 이 평균 −0.91 ± 0.34, 꼬리 −1.97 ± 0.60 이다 (8 절). 인위적 수정 없이 belief 헤징이 평균과 꼬리 모두에서 Nominal 과 Data-DR 을 이기는 첫 설정이다.
- **κ > 0 은 꼬리 우위를 키우지 않는다.** κ = 100, 200 (수요 등식) 의 꼬리 우위는 −1.13 ± 0.31, −1.28 ± 0.44 로 원고 식보다는 크지만 κ = 0 보다 작다 (N_F = 10 에서 쌍별 차 +1.2 ± 0.4). 인스턴스는 κ = 0 을 권고한다 (8 절).

## 2. 원고 식이 안 되는 이유

소매상 belief 는 예약 h 를 통해서만 리더에게 닿는다. belief 가 틀려 예약이 h 에서 h′ 로 바뀔 때 시나리오 s 의 리더 손실 변화는

    Δφ_s = ℓᵀ ( y_s(h′) − y_s(h) )

이다. 원고 식에서 이 값이 작은 이유는 둘이다.

- 예약이 줄어든 만큼 같은 B 거점의 비예약 물량이 대신 팔리고, 두 물량의 리더 계수가 둘 다 −v 다.
- B 의 CVaR 꼬리는 수요가 낮은 시나리오인데, 그때는 예약이 남아 B 의 판매량이 수요로 정해지고 h 와 무관하다.

여기에 더해 후보 결정들이 belief 피해를 같이 입는다. 가장 잘된 설정에서도 헤징으로 줄인 꼬리 피해는 10% 정도였다.

## 4. 기각한 안과 이유

| 안 | 내용 | 기각 이유 (사용자) |
|---|---|---|
| v^S < v | 비예약 물량의 B 마진을 낮춤 | 식을 그렇게 고치는 것은 이상함 |
| B 만 공급 한도 σ | B 거점만 비예약 판매를 제한 | B 에만 거는 것은 이상하고 인위적 |
| 외부 현물시장 | 모든 거점이 예약분만 팔고 부족분은 외부에서 구매 | 원래 문제에 예약을 얹었는데 원래 조달을 없애는 것은 이상함 |
| 리더의 예약 채널 결정 | B 가 거점별로 예약을 받을지 정하는 이진 결정 | 의미가 있는지 불분명. 구현하지 않음 |
| 예약료를 리더 목적에 직접 | q_Bᵀx − r Σ h_i + CVaR[φ] | 리더 목적에 follower 1 단계 변수가 들어감. r = 1, 2 는 효과도 없었음 |

참고로 σ 는 거점 용량 중 비예약으로 팔 수 있는 비율이다 (한도 = σ × 용량).

## 5. 채택 방향: 약정 물량 방식

### 식

    Q(x, h, ξ) = min Σ_{i,j} [ c_ij y^R_ij + (c_ij + p) y^S_ij ] + κ Σ_i s_i
        s.t.  Σ_i (y^R_ij + y^S_ij) ≥ ξ_j                  ∀ j
              Σ_j (y^R_ij + y^S_ij) ≤ b_i (t_i + x_i)       ∀ i
              Σ_j y^R_ij + s_i = h_i                        ∀ i

    φ = max { −v Σ_{i∈I_B} [ Σ_j (y^R_ij + y^S_ij) + s_i ] : (y, s) 가 Q 의 최적해 }

원고 식에서 바뀌는 것은 셋이다. 예약 제약이 등식이 되고 남는 물량 s_i 가 생긴다. 소매상 비용에 κ s_i 가 붙는다. 리더 계수 −v 가 s_i 에도 붙는다. 용량 제약과 예약 범위 H 는 원고 그대로다.

### 원고 식과의 차이

100 을 예약하고 60 만 쓴 경우.

| | 원고 식 | 약정 방식 |
|---|---|---|
| B 가 돈을 받는 물량 | 60 | 100 |
| 남은 40 | 식에 없음 | 소매상 재고, 단위당 κ 부담 |

두 식은 예약이 남는 시나리오, 즉 수요가 낮을 때만 다르고 그 시나리오가 B 의 CVaR 꼬리다. belief 가 비관적이라 예약이 70 으로 줄면 원고 식에서는 꼬리 판매량이 60 그대로지만 약정 방식에서는 100 에서 70 으로 준다.

### OM 해석

- 예약을 "쓸 수 있는 권리" 가 아니라 확정 주문으로 본다. 소매상은 원고에서도 예약료 f 를 쓰든 안 쓰든 낸다. 원고 식은 소매상이 100 에 대해 f 를 내는데 B 는 60 만 판 것으로 잡혀서 오히려 어긋나 있다.
- 소매상은 과잉 한 단위에 f + κ 를 잃고 부족 한 단위에 p − f 를 더 낸다. 표준 뉴스벤더이고, 자기 belief 아래 수요의 1 − (f + κ)/(p + κ) 분위수까지 약정한다.
- Cachon (2004, Management Science 50(2), "The Allocation of Inventory Risk in a Supply Chain: Push, Pull, and Advance-Purchase Discount Contracts") 의 선구매 할인 계약과 같은 구조다. 가격이 둘이고 사전 주문분의 재고 위험은 소매상이 진다. 서지와 초록은 검색으로 확인했다.
- Cachon and Lariviere (2001) 가 확정 주문과 옵션을 함께 다룬다는 것은 초록에서 확인하지 못했다. 본문 확인 전에는 인용하지 않는다.
- 예약 한도 w = 0 이면 Yanıkoğlu–Kuhn, Goyal 의 운송 문제로 그대로 돌아간다.

### 다른 해석 (옵션 계약) 과의 관계

용량 예약 (옵션) 으로 읽으면 남은 40 은 만들지 않은 것이고 B 는 수수료 f 로 보상받는다. 이 경우 B 의 수입은 ρ·h_i + v·(실제 판매) 이고, 남는 물량 변수를 쓰면 이것도 리더 계수만으로 쓸 수 있다 (y^R 에 −(v + ρ), s 에 −ρ, y^S 에 −v). 약정 방식과 같은 계열이다. 사용자는 약정 방식으로 가기로 했다.

## 6. 확인한 것

### 예약 범위를 x 에 의존하게 하면 안 된다

h_i ≤ w_i (t_i + x_i) 로 쓰면 식은 깔끔하지만, 원고의 일반 모형은 H := {h ≥ 0 : Wh ≤ w} 로 x 와 무관하게 정의한다. H(x) 로 넓혔을 때를 본문과 보충자료의 증명으로 확인했다.

| 자리 | H(x) 로 바꾸면 |
|---|---|
| 유한 type 정리 (Theorem 2) | 성립. 다면체 P_x 의 행렬 G 는 x 와 무관하고 x 는 우변에만 들어감 |
| follower 블록 (최적성 벌점) | 성립. 이미 있는 x·λ 선형화로 처리됨 |
| Minimax 정리 (Theorem 1) 의 "Ω 는 x 와 무관" | 깨짐 |

Benders cut 은 어떤 x̄ 에서 구한 응답 h 와 쌍대 변수 ζ 를 고정한 F(x, h, ζ) 이고, 원고는 Theorem 1 (i) 을 근거로 모든 x ∈ X 에서 유효하다고 쓴다 (본문 790~804 행). 보충자료의 Ω 정의에서 x 가 들어올 수 있는 자리는 h ∈ H 하나뿐이다. cut 이 x′ 에서 유효하려면 F(x′, h, ζ) ≤ ν·φ(x′, h) − λ·gap(x′, h) ≤ V*(x′) 가 필요한데, 둘째 부등식은 h 가 x′ 에서도 소매상이 고를 수 있는 응답일 때 (gap ≥ 0) 성립한다. x̄ 에서 구한 h 가 H(x′) 밖이면 두 경우에 보장이 사라진다 (2026-11-14 재확인).

| 범위 밖 h 가 x′ 에서 | 결과 |
|---|---|
| 2 단계 문제를 못 풀게 한다 | φ(x′, h) 가 정의되지 않아 약쌍대성이 상한을 주지 않음 |
| 소매상에게 범위 안 최적보다 유리하다 | gap 이 음수가 되어 벌점이 보상으로 바뀜 |

두 경우가 둘 다 아니면 (범위 밖 h 에서도 2 단계 문제가 풀리고 그 h 가 소매상에게 손해이면) H 를 고정해 두어도 답이 같고 cut 도 유효하다. 원고의 지금 모형과 약정 방식 (용량 제약은 원고 그대로) 이 여기에 해당한다. 따라서 H(x) 는 쓰지 않는다. 이것은 유효성 증명이 깨진다는 확인이고 수치 반례를 계산한 것은 아니다. 응답 h 를 변수로 두는 belief cut 도 h ∈ H(x) 가 필요해 같은 문제가 생긴다.

### 남는 물량을 용량에 넣든 안 넣든 최적해가 같다

같은 거점에서 남은 약정분은 이후 물량보다 단위당 p 만큼 싸다. 그래서 최적해에서 y^S_i > 0 이면 s_i = 0 이다. 남는 물량이 있는 거점은 사용량이 h_i ≤ w_i ≤ b_i 라 용량에 걸리지 않는다. 예약 한도가 용량 이하면 용량 제약에 s_i 를 넣은 식과 안 넣은 식의 최적해 집합이 같다. (논의 중에 "조금 달라진다" 고 한 것은 틀렸고 정정했다.)

그래서 용량 제약은 원고 그대로 두고, "남는 물량이 용량을 차지한다고 보아도 해가 같다" 는 문장으로 OM 해석을 맞춘다.

### 열지 않은 후보지

소매상은 열지 않은 후보지에 예약하지 않는다 (수수료만 나간다). 완화 문제에서도 그런 h 는 리더 손실을 줄이고 벌점까지 받으므로 최악의 경우로 뽑히지 않는다. 최적값에 영향이 없고, 문장 한 줄로 정리한다.

### Recourse 가정

s_i ≥ 0 이 항상 등식을 맞추고 수요는 원고와 같이 A 의 이후 물량으로 채워지므로 relatively complete recourse 가 유지된다. 예약 제약의 쌍대 변수는 −κ 와 p 사이로 묶인다.

## 7. 알고 가야 할 결과와 남은 문제

- **B 는 약정 물량에 대해 수요 위험을 지지 않는다.** B 의 위험이 수요에서 소매상의 예측으로 옮겨 간다. 리더 자신의 분포 모호성 (ε̂) 은 이후 물량에만 걸려 역할이 줄고, Coupled 의 가치는 거의 belief 쪽에서만 나올 수 있다. q̂ 추정 조건 결과에서 따로 본다.
- **마진이 같다는 가정.** 소매상은 사전 물량에 f, 이후 물량에 p 를 내는데 B 의 마진은 둘 다 v 다. 이후 물량은 급히 만들어 비용이 그만큼 더 든다는 가정을 적어야 한다.
- **κ 의 범위.** f + κ > 0.
- **θ^U 재유도.** 저장소의 계산 (`_nz_theta_circuit_exact_pooled`) 은 예약분과 이후 물량의 리더 계수가 같다는 것을 전제한다. 아직 하지 않았다.
- **알고리즘으로 푼 해.** 지금 평가는 후보 결정을 열거한 것이다. α-B&B 로 확인하려면 저장소 코드에 등식 행을 넣어야 하고 허락이 필요하다.

### 3 단계 결과: κ 는 수요 제약이 등식일 때만 작동한다

- 5 절 식 그대로 (수요 제약 ≥) κ = 0, 100, 200 을 지리 1, 시드 1 에서 돌리면 결과가 같다 (동률 처리 수준의 차이만).
- 원인: 각 거점은 같은 도시의 고객과 운송비 0 으로 이어져 있다. 소매상은 남는 예약분을 그 고객에게 초과 배송하면 κ 를 내지 않는다. 최저 수요 시나리오에서 κ = 0 의 남는 물량 351.7 이 κ = 200 에서는 그대로 초과 배송 351.7 로 바뀌고 소매상 비용은 같다. 초과 배송분에도 리더 마진 v 가 붙으므로 리더 값도 같다.
- 따라서 κ 를 쓰려면 수요 제약을 Σ_i (y^R_ij + y^S_ij) = ξ_j 로 써야 한다. 원고 식에서는 ≥ 와 = 가 같은 문제지만 약정 + κ 에서는 다르다. κ = 0 이면 등식으로 써도 결과가 같다 (N 결정의 값만 0.004% 차이).
- 수요 등식에서는 κ 가 작동한다 (지리 1, 시드 1). Nominal 결정의 값이 −3000 → −2755 (κ = 100) → −2742 (κ = 200), 진짜 분포 아래 B 예약량 합이 900 → 851 → 848 이다.
- 같이 본 것: Nominal 결정에서 소매상은 진짜 분포 아래 B 거점마다 예약 한도 300 을 꽉 채운다 (κ = 0). 저수요 쪽으로 치우친 belief 에서는 185, 287, 263 으로 내려간다.

- **Nominal 은 진짜 분포의 주문량에 용량을 맞추고, Belief-only 는 60~77% 의 실행에서 용량을 7~9% 덜 짓는다.** 용량이 결정에 들어가면 입지만으로 하는 헤징은 0 에 가깝고, 꼬리 우위는 거의 전부 용량에서 나온다.
- 용량비가 마진에 가까울수록 크다. 용량이 공짜면 차이가 없다.
- 비용 분포는 위아래 꼬리가 모두 줄고 평균은 약간 오른다 (표본 20 개, c/v 0.5, δ = 0.1 에서 q95 13.1 → 8.7, q05 −10.4 → −8.2, 평균 +0.6). 변동 축소의 전형적인 모양이다.
- 용량이 묶이면 B 가 비예약 판매로 다 팔아 belief 피해가 사라질 것이라는 걱정은 맞지 않았다 (Nominal 의 q90 피해 23%).
- 한계: 용량 수준이 모든 거점 공통이고 간격이 25 (총 용량의 9%) 다. 수준마다 입지 후보는 V_N 상위 8 개다. 30 조합 선별이라 표준오차가 크다. 사전에 적은 비용 규칙 (개설비 500 위에 c·b 를 더함) 은 c/v 0.5 이상에서 아무도 안 여는 퇴화 사례가 되어, 위의 맞춘 규칙으로 판정했다.
