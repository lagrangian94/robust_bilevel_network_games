# 구조 cut 의 증명 메모 (2026-11-21 새벽)

## 대상
belief b = (d, r) 고정, 리더 거점 집합 X (원소 = (거점, 크기 단계)) 의 비관적 리더 비용
V_b(X) = −(1/120) · min{ 리더 수입 : follower 최적 반응 }.

구조 cut:  t0 ≥ V_b(Ŝ) + Σ_{e∉Ŝ} V_b({e}) x_e.
유효성에 필요한 두 성질
- (M) 단조: X ⊆ Y (같은 거점은 같은 크기) 이면 V_b(Y) ≤ V_b(X).
- (S) 서로소 집합의 부분가법: V_b(T ∪ S) ≥ V_b(T) + V_b(S)  (수입으로는 R(T∪S) ≤ R(T) + R(S)).
정수 x 에서: V(X) ≥ V(X∩Ŝ) + Σ_{e∈X∖Ŝ} V(e)  (S 반복)  ≥ V(Ŝ) + Σ_{e∈X∖Ŝ} V(e)  (M).

(S) 는 "T 쪽 수입이 S 를 열어도 늘지 않는다" (집단 대체재) 로 충분하다:
R(T∪S) = R_T(T∪S) + R_S(T∪S) ≤ R(T) + R(S).

## 1 단계 (약정을 시나리오마다 고를 수 있는 경우) 증명
시나리오마다 네트워크: 원천 σ → 거점 노드 i (용량 cap_i) → 고객 j (호 두 개: 약정 비용 f + dist, 상한 w; 추가분 p + dist) → 고객 수요.
- σ 에서 나가는 거점 호들은 언제나 서로 대체재 (Gale–Politof 1981): 용량을 늘린 뒤의 최적 흐름 x′ 과 이전 x 의 차를
  conformal 순환으로 분해하면, 늘린 호를 지나지 않는 순환은 x′ 에서 빼도 최적 (이전 최적성에서 그 순환 비용 ≥ 0) 이므로
  남는 순환은 모두 새로 연 호를 정방향으로 지난다. 단순 순환은 σ 를 한 번 지나므로 σ 의 다른 호 하나를 역방향으로 지나고,
  그 호의 흐름은 줄어든다. 새로 연 호의 흐름은 처음 0 이라 역방향이 될 수 없다.
- 비관적 선택 = follower 비용 − ε·(리더 손실) 섭동 (여전히 최소비용 흐름) 이라 같은 논법.
- 같은 거점 안에서 약정 호가 추가분 호보다 단위당 200 싸고 거리는 같으므로 follower 는 약정부터 채우고,
  거점 수입은 거점 총흐름의 증가함수 → 거점별 수입이 다른 거점을 열면 줄어든다 (시나리오별, 가중 r 과 무관).

## 2 단계 (원래 모형: 약정 h 는 시나리오 공통) — 열린 문제
h_i 가 모든 시나리오의 약정 호 용량이 되어 네트워크가 아니다 (변수 하나가 시나리오마다 복제).
가능한 깨짐: A 의 약정이 여러 시나리오를 묶어 (pooling) 쓰이다가 S 가 한 시나리오의 몫을 가져가면 A 약정이 줄고,
다른 시나리오의 몫을 T 가 받는 경로. → 작은 무작위 예로 반례 탐색 (toy_subst.jl).

## 2 단계 반례 (손으로 만든 것, 약정 공유 경로)
시나리오 둘 (확률 1/2), 고객 1·2. 시나리오 1 은 고객 1 만 수요 D, 시나리오 2 는 고객 2 만 D.
A 는 두 고객에 거리 300, T 거점 a 는 고객 2 옆 (거리 ≈ 0), S 거점 b 는 고객 1 옆. f = 600, p = 800, 용량 ≥ D.
- a 만 열림: A 약정 D 단위를 두 시나리오가 나눠 씀 → 단위당 600 + 300 = 900. (a 추가분 + A 추가분 = 950, a 약정 = 1,000+) → a 수입 0.
- b 만 열림: 대칭으로 b 수입 0.
- 둘 다 열림: 시나리오 1 은 b 추가분, 2 는 a 추가분 → 단위당 800 < 900 → 수입 800 D.
R(T∪S) = 800 D > 0 = R(T) + R(S). A 약정의 공유 (pooling) 가 사라지며 a 와 b 가 보완재가 된다.
무작위 작은 예 (toy_subst.jl, 847 회): 1 단계 모형 위반 0, 2 단계 모형 위반 8 (최대 6.1%).
