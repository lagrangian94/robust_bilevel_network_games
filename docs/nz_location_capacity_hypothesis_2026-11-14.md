# 입지 게임의 가치: 현재 가설과 모형 (2026-11-14 밤 기준)

비제로섬 입지 게임 (원고 6.2 절) 에서 belief 헤징의 가치를 찾는 작업의 현재 위치를 정리한다. 경위와 전체 수치는 `docs/nz_location_formulation_discussion_2026-11-14.md` 8 절에 있다. 여기의 실험은 모두 리더가 진짜 분포를 아는 조건이고, 식과 인스턴스의 원고 반영은 결정 전이다.

## 1. 현재 가설

**follower 의 belief 모호성은 다음 두 조건이 같이 있을 때 리더에게 값어치가 있다.**

1. **확정 주문 계약.** 소매상이 자기 belief 로 주문량을 미리 확정하면 (약정 물량 방식) 소매상의 예측 오차가 주문량 변동으로 리더에게 넘어온다. 쓴 만큼 정산하는 원고 식에서는 belief 가 리더 비용에 거의 영향을 주지 않는다.
2. **리더 쪽의 불일치 비용.** 리더가 주문량에 맞춰 크기를 정하는 결정 (용량) 을 갖고, 그 단위 비용이 단위 마진에 견줄 만해야 한다. Nominal 은 "소매상의 belief = 리더의 분포" 라는 한 점에 용량을 맞추고, belief 헤징은 용량을 덜 지어 변동을 줄인다.

입지만 고르는 리더에게는 둘째 조건이 없다. 비슷하게 좋은 입지 결정들은 belief 가 흔들릴 때 같이 손해를 보기 때문에 (후보 간 피해 상관 0.87), 어느 것을 골라도 belief 에 대한 차이는 비용의 2~3% 다.

가치 지표는 소매상 belief 에 대한 리더 비용의 **위쪽 꼬리** (q90, q95) 다. 평균과 아래쪽 꼬리는 일부 내줘도 된다 (사용자 결정, 2026-11-14).

## 2. 모형

### 2.1 약정 물량 방식 (채택 방향, 원고 미반영)

원고 식 (loc-Q), (loc-φ) 에서 예약을 확정 주문으로 바꾼다. 소매상은 예약한 `h_i` 를 모두 인수하고 쓰지 않은 물량 `s_i` 는 소매상의 재고가 된다.

```
Q(x, h, ξ) = min   Σ_ij [ c_ij y^R_ij + (c_ij + p) y^S_ij ]
             s.t.  Σ_i (y^R_ij + y^S_ij) ≥ ξ_j                     (수요)
                   Σ_j (y^R_ij + y^S_ij) ≤ b_i (t_i + x_i)          (용량)
                   Σ_j y^R_ij + s_i = h_i                           (확정 주문)
                   y, s ≥ 0

φ(x, h, ξ) = max { −v Σ_{i∈I_B} [ Σ_j (y^R_ij + y^S_ij) + s_i ] : (y, s) 가 Q 의 최적해 }
```

- 소매상 1 단계: `h_i ∈ [0, w_i]`, 단가 `f`. 자기 belief 아래 `f Σ h_i + E[Q]` 를 최소화한다. 뉴스벤더이고 분위수는 `1 − f/p` 다.
- 리더: `min Σ q_i x_i + CVaR_β[φ]`, `Σ x_i ≤ r`.
- 원고 식과 다른 점은 예약 제약이 등식이라는 것과 B 의 마진 `v` 가 `s_i` 에도 붙는다는 것이다. 일반 모형과 정리는 그대로다.
- 남는 물량의 단위 비용 `κ` 는 넣지 않는다. `κ ≤ 0` 은 `κ = 0` 과 결과가 같고 `κ > 0` 은 우위를 줄인다.

### 2.2 용량 단계를 더한 식 (제안, 열거 평가는 4.1 절)

거점 `i` 에 용량 단계 `k = 1, …, K` (크기 `b^k`) 를 두고 리더가 어느 거점에 어느 크기로 지을지 고른다.

```
리더   x_i^k ∈ {0, 1},   Σ_k x_i^k ≤ 1 (거점마다),   Σ_i Σ_k x_i^k ≤ r
       비용  Σ_i Σ_k (q_0 + c b^k) x_i^k
용량   Σ_j (y^R_ij + y^S_ij) + s_i ≤ Σ_k b^k x_i^k        (i ∈ I_B)
```

- 나머지는 2.1 과 같다. 용량은 2 단계 제약의 우변에 있으므로 일반 모형 안이다.
- 확정 주문량이 지은 용량을 넘지 못하게 `s_i` 를 용량 제약에 넣는다. 2.1 에서는 용량이 남아서 넣든 안 넣든 같았다.
- `c` 는 단위 용량비, `q_0` 는 크기와 무관한 개설비다.

### 2.3 실제로 돌린 것과의 차이

6 단계 실험은 2.2 의 식을 직접 푼 것이 아니다. 2.1 의 코드에서 B 거점의 물리 용량 `b` 를 200·225·250·275·300·483 으로 바꿔 각각 돌리고, 결정을 (입지, 모든 거점 공통의 용량 수준) 으로 묶어 사후에 비교했다.

| 항목 | 2.2 의 식 | 돌린 것 |
|---|---|---|
| 용량 수준 | 거점마다 따로 | 모든 거점 공통 |
| 수준 간격 | 자유 | 25 (총 용량의 9%) |
| `s_i` 의 용량 제약 포함 | 포함 | 미포함 (소매상이 용량을 넘겨 예약할 유인이 없어 차이는 작을 것으로 보나 확인 안 함) |
| 입지 후보 | 전체 | 수준마다 V_N 상위 8 개 |
| 점포당 비용 | `q_0 + c b^k` | `q_fix + c b`, 용량 300 에서 750 이 되게 `q_fix = 750 − 300c` |

## 3. 마진 이야기

리더는 한 단위를 팔면 `v` (= 5) 를 번다. 용량 한 단위를 짓는 데 `c` 가 든다. 표에 쓴 "단위 용량비/마진" 은 `c/v` 다.

- 지어서 판 단위는 `v − c` 를 남긴다.
- 지었는데 안 팔린 단위는 `c` 를 잃는다.
- 그래서 한 단위를 더 지을지는 그 단위가 팔릴 확률이 `c/v` 를 넘는지로 정해진다. 리더 자신의 뉴스벤더이고, 최적 용량은 주문량 분포의 `(v − c)/v` 분위수다.

"마진이 얇다" 는 것은 `c/v` 가 크다는 뜻이다. 주문량이 belief 에 따라 흔들릴 때 무슨 일이 생기는지 숫자로 보면 다음과 같다. 진짜 분포를 믿는 소매상의 주문이 800 이고, 수요를 낮게 보는 소매상의 주문이 700 이라 하자. Nominal 은 800 을 짓고, 헤징하는 리더는 740 을 짓는다.

| | 주문 800 일 때 이익 | 주문 700 일 때 이익 |
|---|---|---|
| `c/v = 0.5` (c = 2.5), 800 지음 | 4000 − 2000 = 2000 | 3500 − 2000 = 1500 |
| `c/v = 0.5`, 740 지음 | 3700 − 1850 = 1850 (−7.5%) | 3500 − 1850 = 1650 (+10%) |
| `c/v = 0.2` (c = 1), 800 지음 | 4000 − 800 = 3200 | 3500 − 800 = 2700 |
| `c/v = 0.2`, 740 지음 | 3700 − 740 = 2960 (−7.5%) | 3500 − 740 = 2760 (+2%) |

- `c/v = 0.5` 에서는 덜 지어서 잃는 것 (−7.5%) 보다 나쁜 경우에 얻는 것 (+10%) 이 크다.
- `c/v = 0.2` 에서는 남는 용량이 싸서 덜 지을 이유가 없다. 얻는 것이 +2% 뿐이다.

**개설비와 같은 손잡이다.** 지금 인스턴스에서 한 점포가 받을 수 있는 예약은 300 이다. 개설비 500 은 단위당 1.67 (`c/v = 0.33`), 개설비 750 은 단위당 2.5 (`c/v = 0.5`) 에 해당한다. 개설비를 올리면 가치가 커진 것 (5 단계) 과 용량비가 클수록 가치가 큰 것 (6 단계) 은 같은 현상이다. 차이는 단위의 크기다. 개설비는 점포 하나 (총 용량의 1/3) 를 통째로 열거나 닫는 결정이고, 용량 단계는 그것을 잘게 조정한다.

## 4. 증거

값은 Belief-only − Nominal, 리더 비용 대비 %, 평균 · 위쪽 꼬리 (q90). 음수면 Belief-only 가 낫다. 소매상 belief 는 진짜 분포에서 `N_F` 개를 뽑은 경험분포다.

| 구성 | 건수 | N_F = 5 | N_F = 20 |
|---|---|---|---|
| 원고 식 (쓴 만큼 정산) | 75 | +0.11 · −0.26 ± 0.14 | +0.07 · −0.12 ± 0.07 |
| 약정, 개설비 500, 입지만 | 75 | +0.27 · −2.29 ± 0.63 | +0.15 · −1.59 ± 0.45 |
| 약정, 개설비 750, 입지만 | 75 | +0.43 · −4.02 ± 0.80 | +0.61 · −2.27 ± 0.55 |
| 약정, 개설비 1000, 입지만 | 75 | +1.95 · −6.04 ± 1.86 | +1.75 · −3.01 ± 0.92 |
| 약정, 작은 점포 6 곳 (한도 150), 개설비 250 | 30 | +0.02 · −0.75 ± 0.40 | +0.04 · −0.94 ± 0.36 |
| 약정, 작은 점포 6 곳 (한도 150), 개설비 500 | 30 | −0.68 · −3.40 ± 1.06 | −0.25 · −3.02 ± 0.95 |
| 약정, A 거점 4 곳 | 30 | +0.43 · −0.15 ± 0.53 | −0.11 · −1.01 ± 0.61 |
| 약정, 입지 + 용량, `c/v = 0` | 30 | −0.15 · −0.82 ± 0.43 | −0.16 · −0.33 ± 0.67 |
| 약정, 입지 + 용량, `c/v = 0.2` | 30 | +1.25 · −2.82 ± 1.55 | +0.96 · −1.80 ± 0.91 |
| 약정, 입지 + 용량, `c/v = 0.4` | 30 | +1.33 · −3.77 ± 1.16 | +2.52 · −2.53 ± 0.73 |
| **약정, 입지 + 용량, `c/v = 0.5`** | 30 | +0.26 · **−5.20 ± 1.31** | +1.80 · **−3.53 ± 0.76** |
| 같은 설정, 용량은 Nominal 과 같게 두고 입지만 (δ = 0.1) | 30 | +0.33 · +0.47 ± 0.52 | +0.20 · −0.13 ± 0.55 |

모두 보정한 반지름 δ* 기준이고 마지막 줄만 δ = 0.1 이다. 고정 δ = 0.1 로 보면 `c/v = 0.5` 는 N_F = 5 에서 −0.09 · −3.69 ± 1.11, N_F = 20 에서 +0.64 · −3.44 ± 0.91 이다.

- **계약 형태.** 원고 식에서 약정 방식으로 가면 Nominal 의 꼬리 피해가 3% 에서 18% 로, 꼬리 우위가 −0.26 에서 −2.3 으로 커진다.
- **입지만으로는 한계가 있다.** belief 를 뽑기마다 아는 리더도 평균 −2.5, 꼬리 −3.5 를 얻는다. 기존 사업자를 강하게 하면 피해는 23% 로 커지지만 우위는 줄어든다.
- **용량이 결정에 들어가면 가치는 용량에서 나온다.** `c/v = 0.5` 에서 Belief-only 는 60~77% 의 실행에서 용량을 7~9% 덜 짓는다 (총 용량 795 → 720~738). 용량을 Nominal 과 같게 두고 입지만 바꾸면 우위가 0 이다.
- **변동 축소의 모양이다.** N_F = 20, `c/v = 0.5`, δ = 0.1 에서 비용의 q95 가 13.1 → 8.7, q05 가 −10.4 → −8.2 로 줄고 평균은 +0.6 오른다.

### 4.1 거점별 용량 단계 정식 식의 확인 (2026-11-15 새벽 추가, 75 건)

2.2 절의 식을 그대로 평가했다. 결정은 최대 3 곳의 입지와 거점마다 용량 200·250·300 이고 (8,463 개), 남는 물량 `s_i` 를 용량 제약에 넣었다. Nominal 은 전체 열거의 최적이고, Belief-only 는 후보 평균 41 개 (값 상위와 총 용량 구간별 상위 입지) 에서 고른다. 점포 비용은 `q_0 + c b` 이고 용량 300 에서 750 이다.

| `c/v` | `N_F = 5`, 평균 · q90 | `N_F = 20`, 평균 · q90 | 덜 짓는 비율 |
|---|---|---|---|
| 0.5, 보정한 δ | +0.81 ± 0.33 · **−4.03 ± 0.69** [15/0] | +1.00 ± 0.33 · **−3.34 ± 0.45** [15/0] | 69% · 61% |
| 0.5, δ = 0.1 | −0.33 ± 0.31 · −2.99 ± 0.58 [14/1] | +0.40 ± 0.25 · −3.19 ± 0.52 [15/0] | 49% · 49% |
| 0.4, 보정한 δ | +1.26 ± 0.51 · −3.84 ± 0.76 [15/0] | +1.36 ± 0.38 · −3.18 ± 0.47 [15/0] | 68% · 60% |
| 0.2, 보정한 δ | +2.23 ± 0.50 · −3.67 ± 0.91 [13/2] | +1.94 ± 0.49 · −2.41 ± 0.48 [14/1] | 72% · 60% |

- 위쪽 꼬리 우위는 −3~−4% 이고 평균은 0.4~1.0% 손해다 (`c/v` 0.4 이상). 문헌 범위인 `c/v = 0.4` 에서도 크기가 같다.
- 분해 (`c/v = 0.5`, 보정한 δ, `N_F` 5 · 20). 입지만 바꾸면 −0.86 · −0.97, 용량만 바꾸면 −1.51 · −1.11, 둘 다 바꾸면 −4.03 · −3.34 이다. 입지와 용량을 같이 바꿔야 가치가 난다.
- 위 표의 30 조합 결과 (−5.20) 는 재현되지 않았다. 그 실험은 용량 수준이 거점 공통이라 Nominal 이 거칠었고, 거점별로 맞춘 Nominal 보다 진짜 분포 아래 값이 평균 6.2% 나빴다. −5.20 은 덜 맞춘 Nominal 대비 우위다.
- 후보 수의 영향. 후보가 값 상위 18 개뿐이면 −2.80 · −2.51 이다. 총 용량 구간마다 상위 입지를 1·2·3 개 더하면 −3.66, −3.77, −4.03 (`N_F = 5`) 으로, 증가폭은 작아지지만 완전히 멈추지는 않는다. Belief-only 의 정확한 해는 알고리즘으로 풀어야 확정된다.
- 그림 `docs/figs/nz_location_takeorpay/tk_cost_boxplot_tier_nf{5,20}.png`. 스크립트는 스크래치패드의 `tkT.jl`, `tkU.jl`, `agg_tier2.py`, `box_tier.py`, 예측과 판정은 `cf_predictions.txt` H47·H48.

## 5. 확인하지 않은 것

- 2.2 의 식을 직접 푼 결과가 없다. 거점별 용량 단계에서 우위가 더 커지는지, 그대로인지 모른다.
- 용량 실험은 30 조합 선별이다. 표준오차가 0.8~1.3 이다.
- 리더가 q̂ 를 추정하는 조건의 결과는 개설비 500·입지만에서만 있다 (Belief-only − Nominal 평균 −1.07 ± 0.36, 꼬리 −1.48 ± 0.52). 개설비 750 과 용량 설정에서는 없다.
- 평가는 후보 결정의 열거다. 원고의 알고리즘으로 푼 해가 아니다.
- `c/v` 의 근거 있는 값이 필요하다. 결과를 보고 고른 값이라는 지적을 받을 수 있다. 개설비 750 은 Yanıkoğlu–Kuhn 의 무작위 인스턴스와 원고 계산 실험의 값이다.
- 6 단계의 사전 예측에 적은 비용 규칙 (개설비 500 위에 `c b` 를 더함) 은 `c/v ≥ 0.5` 에서 아무도 열지 않는 사례가 되어 쓰지 못했다. 표의 규칙 (`q_fix = 750 − 300c`) 은 집계 스크립트에 결과를 보기 전에 넣었지만 예측 파일에는 적지 않았다.
- `κ > 0` 과 `f/p = 0.5` 가 우위를 줄이는 원인은 찾지 못했다.

## 8. 추가 주문과 belief 헤징의 긴장 관계 (2026-11-15, 원고 반영 방향 모색)

사용자 판단 (2026-11-15): 이 긴장 관계는 우리 이론의 중요한 지점일 수 있다. 원고에 넣을 방향을 찾는다. 아래는 메모이고 원고 tex 에는 아직 아무것도 반영하지 않았다.

### 8.1 긴장 관계

- 추가 주문은 리더에게 belief 오류에 대한 자연 보험이다. 소매상이 수요를 낮게 믿어 적게 약정해도, 수요가 실제로 있으면 남은 용량에서 추가 주문으로 사 간다. 리더는 그만큼 판매를 되찾는다.
- 그래서 추가 주문의 몫이 커질수록 belief 를 잘못 짚은 피해가 줄고, belief 모호성을 헤징할 이유도 줄어든다.
- 반대로 추가 주문이 없으면 리더의 판매는 약정량 $h$ 로 고정된다. 리더 비용이 실현 수요와 무관해지므로 자료 모호성을 헤징할 것이 없다 (Data-DR 이 Nominal 과 같은 결정).
- 정리하면 자료 모호성의 가치는 추가 주문에서 나오고, belief 모호성의 가치는 약정에서 나온다. 둘은 같은 판매량을 나눠 갖는다.

### 8.2 거점 하나로 본 논리

거점 하나, 용량 $b$, 약정량 $h$, 수요 $\xi$ 로 단순화한다.

- 소매상은 약정 한 단위에 $f$ 를 미리 내고, 약정으로 모자라는 물량은 단위당 $p$ 를 더 내고 추가 주문한다. 소매상의 약정량은 자기 belief 아래 수요의 $1 - f/p$ 분위수다.
- B 의 판매량은 $\max\{h, \min(\xi, b)\}$ 이다. 수요가 약정량보다 작으면 판매 $= h$ (약정분은 모두 인수), 크면 판매 $= \min(\xi, b)$.
- 소매상이 belief 오류로 $h' < h$ 를 약정하면 리더의 판매 손실은 $(h - \max\{h', \xi\})^+$ 이다. 손실은 $\xi < h$ 인 시나리오에서만 생기고, $\xi \ge h$ 인 시나리오에서는 추가 주문이 메운다 (여유 용량이 있을 때).
- 리더의 $\mathrm{CVaR}_\beta$ 는 판매가 낮은 $1-\beta$ 비율의 시나리오만 본다. 그 안에서 $\xi < h$ 인 몫은 $\min\{1, (1 - f/p)/(1-\beta)\}$ 이고 이것이 belief 쪽 노출, 나머지 $1 - (1 - f/p)/(1-\beta)$ 가 자료 쪽 노출이다.
- 리더가 여유 용량 ($b > h$) 을 지으려면 그 용량이 CVaR 이 보는 시나리오에서 쓰일 몫이 단위 용량비/마진 $c/v$ 를 넘어야 한다.

$\beta = 0.4$ 에서의 귀결.

| $f/p$ | CVaR 이 보는 시나리오 중 추가 주문 몫 | 귀결 |
|---|---|---|
| $\le 0.4$ | 0 | 판매 $= h$ 로 평평. 자료 노출 0, belief 만 남음 |
| 0.5 | 1/6 | $c/v \ge 0.2$ 면 리더가 여유 용량을 안 지음. 자료 노출 0 |
| 0.6 | 1/3 | $c/v = 0.2$ 에서만 여유 용량 |
| 0.67 | 0.45 | $c/v \le 0.4$ 에서 여유 용량 |
| 0.75 | 0.58 | $c/v \le 0.5$ 에서 여유 용량 |
| $\to 1$ | 1 | 약정 없음 = 원고의 쓴 만큼 정산 식. belief 무관 |

원고의 현재 식 (쓴 만큼 정산) 은 이 축의 한쪽 끝이고, 4 절까지의 약정 방식 결과 ($f/p = 0.25$) 는 반대쪽 끝이다.

### 8.4 원고에 넣을 방향 (모색, 미결정)

1. **계약 구조를 한 축으로 제시.** $f/p$ (약정 한 단위의 선불 비용 대 추가 주문의 웃돈) 를 가로축에 두면 쓴 만큼 정산 ($f/p \to 1$) 과 확정 약정 ($f/p$ 작음) 이 한 모형의 양 끝이 된다. 지금 원고 식은 그 끝점으로 남고, 약정 방식은 "다른 모형" 이 아니라 같은 모형의 다른 구간이 된다.
2. **가치가 어디서 나오는지에 대한 명제 또는 Remark.** 거점 하나 뉴스벤더에서 belief 오류의 손실이 $(h - \max\{h', \xi\})^+$ 이고 추가 주문이 $\xi \ge h$ 쪽을 메운다는 것, $\mathrm{CVaR}_\beta$ 아래 두 노출의 몫이 $(1 - f/p)/(1-\beta)$ 로 갈린다는 것. 6.2 절의 수치 결과를 읽는 틀이 된다.
3. **결합 모형의 자리.** 두 노출이 같이 있는 구간 ($f/p$ 0.67~0.75) 에서만 결합 모형이 Data-DR 과 Belief-only 를 모두 앞설 여지가 있다. 양 끝에서는 한쪽 모형으로 충분하다. 이 구간의 자료 세계 결과가 나와야 주장할 수 있다 (실행 중).
4. **그림 후보.** 가로 $f/p$, 세로 Nominal 대비 꼬리 우위, 선은 Data-DR·Belief-only·결합. 두 가치가 엇갈리는 모양이 나오면 논문의 "언제 어떤 모호성이 중요한가" 에 대한 답이 된다.

### 8.5 확인하지 않은 것

- 8.2 는 거점 하나의 논리다. 네트워크에서는 B 가 기저 물량을 먼저 맡고 변동분은 다른 거점이 받을 수 있어서 도시 조합 간 편차가 크다 (추가 주문 1% 인 조합과 12% 인 조합이 같은 설정 안에 있음).
- $f/p$ 0.67~0.75 의 헤징 가치는 15 건씩이다. 이후 경과는 8.7·8.8 에 있다.
- $\beta$ 를 바꾸면 문턱이 $(1-\beta)$ 로 움직일 것이라는 예측은 시험하지 않았다. $\beta = 0.4$ 는 두 게임 공통 규칙이라 고정이다.
- 예측과 판정 기록은 `cf_predictions.txt` 의 H49~H53.

### 8.6 소매상 모형의 문헌상 위치 (2026-11-15, 인용 후보, 원고 bib 에는 아직 없음)

원고는 Yanıkoğlu–Kuhn (2018) 과 Goyal et al. (2023) 의 수송 recourse 에 예약 단계를 덧붙였고, 예약 구조 자체에는 인용이 없다. 구조는 공급 계약 문헌의 표준 형태다.

- 용량 예약 계약 + 현물 시장 (예약 단가를 미리 내고, 모자라면 현물로 삼): Wu, Kleindorfer, Zhang (2002, EJOR), Kleindorfer and Wu (2003, Management Science), Wu and Kleindorfer (2005, Management Science), Serel, Dada, Moskowitz (2001, EJOR 131(3), 635–648).
- 옵션 계약 묶음과 현물 시장: Martínez-de-Albéniz and Simchi-Levi (2005, POM 14(1), 90–114).
- 확정 약정 (최소 인수 물량): Bassok and Anupindi (1997, IIE Transactions 29(5), 373–381).
- 대응: 우리 $f$ = 예약 단가, $p$ = 현물 웃돈, 원고 식은 실행 단가 0 인 용량 옵션 (쓴 만큼만 인수), 약정 방식은 예약분을 모두 인수하는 확정 약정.
- 서지 사항은 검색으로 확인했고 본문은 아직 읽지 않았다. 인용 전에 각 논문의 모형이 위 대응과 맞는지 확인해야 한다.

## 9. 모형 점검 (2026-11-15 오후): 소매상 단독 문제와 "진짜 분포를 모르는 것" 의 경로

사용자 요청으로 실험을 멈추고 모형부터 다시 본 것이다. 새 실험은 없고, 소매상 문제를 원자료 (거리·수요·용량) 에서 따로 세워 푼 진단 (`ret_diag.jl`, 지리 g1~4 × 시드 1, 리더 결정은 그 구성의 Nominal 결정) 과 기존 자료 세계 결과의 재집계 (`agg_regret.py`) 다.

### 9.1 소매상의 문제 (리더 결정을 고정)

$$\min_{0 \le h_i \le \min(w, b_i)}\; f\sum_i h_i + \mathbb{E}_d\Bigl[\min_{y \ge 0} \sum_{i,j} c_{ij}\,y^R_{ij} + (c_{ij} + p)\,y^S_{ij}\Bigr] \quad \text{s.t.}\quad \sum_i (y^R_{ij} + y^S_{ij}) \ge \xi_j,\;\; \sum_j y^R_{ij} \le h_i,\;\; \sum_j (y^R_{ij} + y^S_{ij}) \le b_i .$$

- 거점은 A 2 곳 (용량 각 약 725) 과 리더가 연 B 세 곳 이하. 고객은 15 개 도시 전부. 총수요는 약 800~1,200.
- 약정 물량 방식은 소매상의 문제를 바꾸지 않는다. 바뀌는 것은 리더의 수입 ($v \times$ 약정량 + 추가 주문) 뿐이다.

| 예약료 비율 | VSS | EVPI | 추가 주문 / 총수요 | B 약정이 상한에 붙은 거점 | 리더 판매의 범위 (시나리오 10 개) |
|---|---|---|---|---|---|
| 0.25 | 1.9~4.2% | 4.4~6.7% | 0.2~1.0% | 12 곳 중 8 | 900~900, 858~874, 837~850, 800~800 |
| 0.5 | 0.1~0.6% | 3.9~6.7% | 3.1~5.2% | 12 곳 중 8 | 800~800, 700~700, 772~800, 698~700 |
| 0.75 | 0.7~1.6% | 2.8~4.5% | 8.6~19.7% | 12 곳 중 5 | 747~800, 604~700, 702~800, 684~700 |

- **잘 정의되어 있다.** 수요는 항상 충족되고 (A 총용량 > 최대 총수요), 소매상의 최적 약정량은 유일했고 (B 약정 합의 범위 폭 ≤ 0.1), 2 단계에서 리더 판매가 달라지는 동률도 사실상 없었다 (평균 폭 ≤ 1.6).
- **확률계획으로서 자명하지는 않다.** 수송비가 소매상 비용의 41~71% 이고 EVPI 3~7%, VSS 는 예약료 0.25 에서 2~4%, 0.75 에서 1% 안팎이다. 예약료 0.5 는 VSS 0.1~0.6% 로 가장 밋밋하다.
- **다만 B 거점에서는 뉴스벤더 균형이 절반쯤만 작동한다.** B 의 좋은 거점은 약정량이 상한 (예약 상한 300 또는 점포 용량) 에 붙는다. 균형이 살아 있는 곳은 A 거점 (항상 내부해) 과 B 의 한두 거점이다.
- **B 는 늘 거의 다 팔린다.** 리더 판매는 약정량 $h_B$ 와 총 용량 사이에 갇힌다. 그 폭이 예약료 0.25 에서 0~2%, 0.75 에서 2~14% 다. 리더가 용량비 0.5 에서 팔릴 만큼만 짓기 때문이다.
- **소매상의 추가 주문은 대부분 A 로 간다** (예약료 0.75 에서 A 62~138, B 7~54). B 에는 남는 용량이 적어서다.
- 예약 상한 $w = 300$ 은 용량 400 인 점포에서 약정을 300 으로 막아 추가 주문을 억지로 만든다. 본 구성의 용량비 0.5 에서는 400 이 쓰이지 않아 해당이 없고, 용량비 0.2 의 큰 추가 주문 (13.6%) 에는 이 효과가 섞여 있다.

### 9.2 리더가 진짜 분포를 모르는 것은 어떤 경로로 리더에게 영향을 주나

자료 세계에서 리더는 표본 10 개 ($\hat q$) 로 결정하고 진짜 분포에서 평가받는다. Nominal 결정의 손해를 두 경우로 나눠 쟀다 (리더 비용 대비 %, 용량비 0.5).

| | 예약료 0.25 (75 건) | 예약료 0.75 (45 건) |
|---|---|---|
| **소매상 belief = 리더의 $\hat q$ 일 때** (리더의 자료 오차만 남음) | | |
| Nominal 이 사후 최선 후보인 비율 | 99% | 78% |
| Nominal 의 사후 손해 (평균) | 0.00 | 0.29 (용량비 0.4 는 0.96) |
| **소매상 belief 가 소매상 자신의 표본일 때** | | |
| 소매상 belief 가 $\hat q$ 와 달라서 늘어난 비용 (표본 5 · 20 개) | +9.7 · +5.5 | +3.5 · +5.3 |
| Nominal 의 사후 손해 (평균, 표본 5 · 20 개) | 2.3 · 2.3 | 1.8 · 1.7 |

- **직접 경로는 거의 없다.** 리더 판매가 $h_B$ 와 용량 사이에 갇혀 있어서, 진짜 수요가 표본과 달라도 리더 비용은 그 좁은 폭 안에서만 움직인다. 예약료 0.25 에서는 폭이 0 이라 손해가 정확히 0 이고, 0.75 에서도 0.3~1.0% 다. Data-DR 이 얻을 수 있는 몫의 상한이 이만큼이다.
- **간접 경로가 전부다.** 진짜 분포를 모른다는 것이 리더에게 아픈 이유는 소매상이 무엇을 믿는지 모르기 때문이다. 소매상 belief 가 $\hat q$ 와 다르면 약정량이 달라지고 비용이 3.5~10% 늘어난다.
- 그래서 지금 구성에서 "자료 불확실성" 은 사실상 "belief 불확실성" 의 다른 이름이다. 리더의 $\hat q$ 는 소매상 belief 의 (부정확한) 대용물로만 쓰인다.
- **주의 (같은 날 바로잡음).** 위 표의 "사후 최선" 은 모형들이 고른 결정 (Nominal, Data-DR 세 반지름, Belief-only 네 반지름, 결합, 최대 9 개) 안에서의 최선이다. 자료 세계 스크립트가 진짜 분포 평가를 그 결정들에만 했기 때문이다. 그래서 "Data-DR 이 얻을 수 있는 몫의 상한" 이라는 말은 지나쳤고, 정확히는 "어느 모형의 결정도 Nominal 을 그 이상 이기지 못했다" 이다. 넓은 후보 (상위 30 개 + 총 용량별 최선) 에 대한 사후 손해는 `expoR.jl` 선별 (대장 4.9) 에서 재는 중이다. 예약료 0.25 에서 손해가 0 이라는 것은 구조적 이유 (판매 = 약정량) 로 설명되지만, 0.75 의 0.3~1.0 은 하한으로 읽어야 한다.

### 9.3 문헌상 위치 (2026-11-15, 서브에이전트 조사. 8.6 을 보완)

| 갈래 | 핵심 문헌 | 우리 모형과의 관계 |
|---|---|---|
| 수송 recourse 가 있는 2 단계 확률계획 | Dantzig (1955, Management Sci.), Williams (1963, Oper. Res.), Louveaux (1986, Ann. Oper. - **추가 공급을 다루는 관례는 둘이고 우리 것은 어느 쪽도 아니다.** (가) 웃돈이나 벌점으로 무제한 (Williams, Wu–Kleindorfer, Özer–Uncu–Wei), (나) 공급자 용량으로 제한하고 넘는 수요는 잃음 (Harrison–Van Mieghem, Van Mieghem–Rudi). 우리는 "용량으로 제한 + 수요는 반드시 충족" 이라 실행가능성을 경쟁자 A 의 용량이 보장해야 한다. 원고에 가정으로 적기로 한 것 (A 총용량 ≥ 최대 총수요) 이 바로 이 자리다.
- **팔로워 동률.** Wu–Kleindorfer (2005) 는 동률 배분 규칙을 가정으로 두고 결과가 그 규칙에 달릴 수 있다고 적는다. 우리는 비관적 동률이고, 9.1 의 진단에서 동률은 사실상 없었다.
- **공급자 수입.** 확정분은 쓰든 안 쓰든 수입이 되고 추가분도 수입이 되는 꼴은 Cachon (2004), Dong–Zhu (2007) 계열과 같다.
- **읽는 틀로 쓸 수 있는 것.** Cachon (2004) 은 재고 위험을 누가 지는가로 계약을 나눈다 (구매자가 지면 push, 공급자가 지면 pull, 할인 선구매는 둘이 나눔). 우리 예약료 비율이 그 손잡이다. 낮으면 소매상이 위험을 다 지고 (리더 판매 = 약정량), 높이면 리더가 남는 용량만큼 위험을 진다. 9.2 의 "직접 경로" 는 리더가 지는 몫과 같다. (Cachon 본문은 아직 읽지 않았다.)
- 서지 불일치: Snyder (2006) 쪽수는 537–554 와 547–564 가 섞여 있고, Louveaux (1986) 은 21–34 와 23–34 가 섞여 있다. Kleindorfer–Wu (2003) 는 모형 논문이 아니라 서베이다.

### 9.4 용량비를 내리면 리더가 수요 위험을 지는가 (2026-11-15 저녁, 선별 `expo13`·`expo14`, 지리 4 개 × 시드 1)

예약료 0.75, 용량 메뉴 200·300·400·500. 직접 손해는 Nominal 의 진짜 분포 비용을 넓은 후보 (값 상위 30 개 + 총 용량별 최선 + Data-DR 결정, 약 40 개) 의 사후 최선과 비교한 것이고, 소매상 belief 는 리더의 추정과 같다고 둔다. 값은 지리 4 개의 평균 (괄호 안은 지리별).

| 용량비 | 예약 상한 | 판매 폭 (용량 − 약정)/용량 | 직접 손해 (%) | Data-DR − Nominal (%) |
|---|---|---|---|---|
| 0.5 | 500 | 8.7% (7, 14, 12, 2) | 0.04 (0, 0, 0.1, 0) | +0.8 (+3.3, 0, −0.1, 0) |
| 0.4 | 500 | 10.7% (7, 22, 12, 2) | 1.2 (0, 4.6, 0, 0) | −1.2 (0, −4.6, 0, 0) |
| 0.2 | 500 | 17.4% (7, 38, 23, 2) | 2.6 (0, 10.1, 0.2, 0) | −2.6 (0, −10.1, −0.2, 0) |
| 0.2 | 300 | 28.6% (25, 38, 23, 29) | 4.0 (1.1, 10.1, 0.2, 4.6) | −4.0 (−1.1, −10.1, −0.2, −4.6) |

- **방향은 예상대로다.** 용량비를 내리면 리더가 여유 용량을 짓고, 판매 폭이 넓어지고, 진짜 분포를 모르는 것의 직접 손해가 생기고, Data-DR 이 그만큼 Nominal 을 이긴다. 용량비 0.5 에서는 넓은 후보와 비교해도 직접 손해가 0.04% 다 (9.2 의 정정에 대한 답).
- **다만 지리 한 곳 (g2) 이 거의 전부를 끌고 간다.** g2 의 Nominal 은 표본 10 개를 믿고 용량 1,000 을 지었다가 진짜 분포에서 추가 주문이 171 에서 125 로 줄었다 (낙관 오차 20%). Data-DR 은 800 을 짓고 10% 이긴다. 4 건 중 한 건이라 크기는 믿을 수 없다.
- **예약 상한을 500 으로 풀면 리더가 위험을 피하는 길이 생긴다.** g1·g4 에서 리더는 큰 점포 하나에 몰아 짓고 (예 {8:300; 13:500}) 소매상이 거기에 500 까지 약정해서 계속 다 팔린다. 예약 상한 300 에서는 약정이 300 에 막혀 판매 폭이 네 곳 모두 23~38% 로 벌어진다. 이 폭은 리더가 고른 것이 아니라 상한이 만든 것이다.
- **지리 안에서도 긴장이 보인다.** 판매 폭이 큰 g2 는 belief 노출이 2.9 이고, 폭이 없는 g4 는 19.5 다. 리더가 수요 위험을 지는 곳에서는 belief 가 덜 중요하다.

### 9.5 "리더가 수요 위험을 지면 belief 가 덜 중요한가" 의 수리적 형태 (2026-11-15, 한 거점 모형)

거점 하나, 용량 $b$, 약정량 $h \le b$, 그 거점으로 오는 수요 $\xi$. 약정 물량 방식에서 리더 판매는 수요를 구간 $[h, b]$ 로 자른 값이다.

$$\text{판매}(\xi) = h + \min\{(\xi - h)^+,\; b - h\} = \operatorname{med}(h, \xi, b), \qquad R(\xi) = v \cdot \operatorname{med}(h, \xi, b).$$

**시나리오는 셋 중 하나에 든다.** $\xi < h$ 이면 수입은 $vh$ (약정량만 결정, 수요 무관). $h < \xi < b$ 이면 $v\xi$ (수요만 결정, 약정량 무관). $\xi > b$ 이면 $vb$ (용량만 결정). 따라서

$$\underbrace{G(h)}_{\text{belief 몫}} + \underbrace{G(b) - G(h)}_{\text{수요 몫}} + \underbrace{1 - G(b)}_{\text{매진 몫}} = 1 .$$

**두 오차의 크기.**

- 자료 오차. 수요 분포가 $G$ 가 아니라 $G'$ 이면 $\lvert \mathbb{E}_G R - \mathbb{E}_{G'} R \rvert \le v\,(b - h)\,\mathrm{TV}(G, G')$. $R$ 이 $[vh, vb]$ 안에 있기 때문이다. $b = h$ 이면 정확히 0 이다.
- belief 오차. 소매상이 $h$ 대신 $h' < h$ 를 약정하면 $\mathbb{E}_G[R_h - R_{h'}] = v \int_{h'}^{h} G(t)\,dt \le v\,(h - h')\,G(h)$. 용량 $b$ 와 무관하다.

**CVaR 꼬리 안의 몫** (리더는 수입이 낮은 $(1-\beta)$ 만큼, 곧 저수요 쪽을 본다. 소매상은 $G(h) = 1 - f/p$ 까지 약정하고, 리더는 꼬리 안 매진 비율이 $c/v$ 가 될 때까지 짓는다).

$$B = \min\Bigl\{1, \frac{1 - f/p}{1 - \beta}\Bigr\}, \qquad D = \max\{0,\; 1 - c/v - B\}, \qquad \text{매진} = \min\{c/v,\; 1 - B\}, \qquad B + D + \text{매진} = 1 .$$

| $\beta = 0.4$ | belief 몫 $B$ | 수요 몫 $D$ | 매진 몫 |
|---|---|---|---|
| 예약료 0.25, 용량비 아무 값 | 1 | 0 | 0 |
| 예약료 0.5, 용량비 0.5 | 0.83 | 0 | 0.17 |
| 예약료 0.75, 용량비 0.5 | 0.42 | 0.08 | 0.5 |
| 예약료 0.75, 용량비 0.2 | 0.42 | 0.38 | 0.2 |

- 여유 용량이 생기는 조건은 $(1-\beta)(1 - c/v) > 1 - f/p$ 이다. 8.2 의 문턱과 같은 식이고, 2 차 선별 표 (예약료 0.5 는 어느 용량비에서도 추가 주문 없음, 0.75 는 용량비가 낮을수록 큼) 와 맞는다.
- **예약료를 올리면 belief 몫이 수요 몫으로 일대일로 옮겨 간다.** 8.1 의 긴장 관계가 이 축이다.
- **용량비를 내리면 매진 몫이 수요 몫으로 옮겨 가고 belief 몫은 그대로다.** 그러니 "리더가 수요 위험을 지면 belief 가 덜 중요하다" 는 예약료 축에서만 성립하는 말이고, 용량비 축에서는 한 거점 모형으로는 성립하지 않는다. 9.4 에서 지리 2 (판매 폭 큼, belief 노출 2.9) 와 지리 4 (폭 없음, 19.5) 를 보고 한 말은 지리 네 곳의 관찰이었지 일반 명제가 아니다.
