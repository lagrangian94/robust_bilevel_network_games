# 입지 게임의 가치: 현재 가설과 모형 (2026-11-14 밤 기준)

비제로섬 입지 게임 (원고 6.2 절) 에서 belief 헤징의 가치를 찾는 작업의 현재 위치를 정리한다. 경위와 전체 수치는 `docs/nz_location_formulation_discussion_2026-11-14.md` 8 절에 있다. 여기의 실험은 모두 리더가 진짜 분포를 아는 조건이고, 식과 인스턴스의 원고 반영은 결정 전이다.

## 1. 현재 가설

**follower 의 belief 모호성은 다음 두 조건이 같이 있을 때 리더에게 값어치가 있다.**

1. **확정 주문 계약.** 소매상이 자기 belief 로 주문량을 미리 확정하면 (약정 물량 방식) 소매상의 예측 오차가 주문량 변동으로 리더에게 넘어온다. 쓴 만큼 정산하는 원고 식에서는 belief 가 리더 비용에 거의 영향을 주지 않는다.
2. **리더 쪽의 불일치 비용.** 리더가 주문량에 맞춰 크기를 정하는 결정 (용량) 을 갖고, 그 단위 비용이 단위 마진에 견줄 만해야 한다. Nominal 은 "소매상의 belief = 리더의 분포" 라는 한 점에 용량을 맞추고, belief 헤징은 용량을 덜 지어 변동을 줄인다.

입지만 고르는 리더에게는 둘째 조건이 없다. 비슷하게 좋은 입지 결정들은 belief 가 흔들릴 때 같이 손해를 보기 때문에 (후보 간 피해 상관 0.87), 어느 것을 골라도 belief 에 대한 차이는 비용의 2~3% 다.

가치 지표는 소매상 belief 에 대한 리더 비용의 **위쪽 꼬리** (q90, q95) 다. 평균과 아래쪽 꼬리는 일부 내줘도 된다 (사용자 결정, 2026-11-14).

## 2. 모형

### 2.1 약정 물량 방식 (채택 방향, 원고 미반영)

원고 식 (loc-Q), (loc-φ) 에서 예약을 확정 주문으로 바꾼다. 소매상은 예약한 `h_i` 를 모두 인수하고 쓰지 않은 물량 `s_i` 는 소매상의 재고가 된다.

```
Q(x, h, ξ) = min   Σ_ij [ c_ij y^R_ij + (c_ij + p) y^S_ij ]
             s.t.  Σ_i (y^R_ij + y^S_ij) ≥ ξ_j                     (수요)
                   Σ_j (y^R_ij + y^S_ij) ≤ b_i (t_i + x_i)          (용량)
                   Σ_j y^R_ij + s_i = h_i                           (확정 주문)
                   y, s ≥ 0

φ(x, h, ξ) = max { −v Σ_{i∈I_B} [ Σ_j (y^R_ij + y^S_ij) + s_i ] : (y, s) 가 Q 의 최적해 }
```

- 소매상 1 단계: `h_i ∈ [0, w_i]`, 단가 `f`. 자기 belief 아래 `f Σ h_i + E[Q]` 를 최소화한다. 뉴스벤더이고 분위수는 `1 − f/p` 다.
- 리더: `min Σ q_i x_i + CVaR_β[φ]`, `Σ x_i ≤ r`.
- 원고 식과 다른 점은 예약 제약이 등식이라는 것과 B 의 마진 `v` 가 `s_i` 에도 붙는다는 것이다. 일반 모형과 정리는 그대로다.
- 남는 물량의 단위 비용 `κ` 는 넣지 않는다. `κ ≤ 0` 은 `κ = 0` 과 결과가 같고 `κ > 0` 은 우위를 줄인다.

### 2.2 용량 단계를 더한 식 (제안, 아직 구현 전)

거점 `i` 에 용량 단계 `k = 1, …, K` (크기 `b^k`) 를 두고 리더가 어느 거점에 어느 크기로 지을지 고른다.

```
리더   x_i^k ∈ {0, 1},   Σ_k x_i^k ≤ 1 (거점마다),   Σ_i Σ_k x_i^k ≤ r
       비용  Σ_i Σ_k (q_0 + c b^k) x_i^k
용량   Σ_j (y^R_ij + y^S_ij) + s_i ≤ Σ_k b^k x_i^k        (i ∈ I_B)
```

- 나머지는 2.1 과 같다. 용량은 2 단계 제약의 우변에 있으므로 일반 모형 안이다.
- 확정 주문량이 지은 용량을 넘지 못하게 `s_i` 를 용량 제약에 넣는다. 2.1 에서는 용량이 남아서 넣든 안 넣든 같았다.
- `c` 는 단위 용량비, `q_0` 는 크기와 무관한 개설비다.

### 2.3 실제로 돌린 것과의 차이

6 단계 실험은 2.2 의 식을 직접 푼 것이 아니다. 2.1 의 코드에서 B 거점의 물리 용량 `b` 를 200·225·250·275·300·483 으로 바꿔 각각 돌리고, 결정을 (입지, 모든 거점 공통의 용량 수준) 으로 묶어 사후에 비교했다.

| 항목 | 2.2 의 식 | 돌린 것 |
|---|---|---|
| 용량 수준 | 거점마다 따로 | 모든 거점 공통 |
| 수준 간격 | 자유 | 25 (총 용량의 9%) |
| `s_i` 의 용량 제약 포함 | 포함 | 미포함 (소매상이 용량을 넘겨 예약할 유인이 없어 차이는 작을 것으로 보나 확인 안 함) |
| 입지 후보 | 전체 | 수준마다 V_N 상위 8 개 |
| 점포당 비용 | `q_0 + c b^k` | `q_fix + c b`, 용량 300 에서 750 이 되게 `q_fix = 750 − 300c` |

## 3. 마진 이야기

리더는 한 단위를 팔면 `v` (= 5) 를 번다. 용량 한 단위를 짓는 데 `c` 가 든다. 표에 쓴 "단위 용량비/마진" 은 `c/v` 다.

- 지어서 판 단위는 `v − c` 를 남긴다.
- 지었는데 안 팔린 단위는 `c` 를 잃는다.
- 그래서 한 단위를 더 지을지는 그 단위가 팔릴 확률이 `c/v` 를 넘는지로 정해진다. 리더 자신의 뉴스벤더이고, 최적 용량은 주문량 분포의 `(v − c)/v` 분위수다.

"마진이 얇다" 는 것은 `c/v` 가 크다는 뜻이다. 주문량이 belief 에 따라 흔들릴 때 무슨 일이 생기는지 숫자로 보면 다음과 같다. 진짜 분포를 믿는 소매상의 주문이 800 이고, 수요를 낮게 보는 소매상의 주문이 700 이라 하자. Nominal 은 800 을 짓고, 헤징하는 리더는 740 을 짓는다.

| | 주문 800 일 때 이익 | 주문 700 일 때 이익 |
|---|---|---|
| `c/v = 0.5` (c = 2.5), 800 지음 | 4000 − 2000 = 2000 | 3500 − 2000 = 1500 |
| `c/v = 0.5`, 740 지음 | 3700 − 1850 = 1850 (−7.5%) | 3500 − 1850 = 1650 (+10%) |
| `c/v = 0.2` (c = 1), 800 지음 | 4000 − 800 = 3200 | 3500 − 800 = 2700 |
| `c/v = 0.2`, 740 지음 | 3700 − 740 = 2960 (−7.5%) | 3500 − 740 = 2760 (+2%) |

- `c/v = 0.5` 에서는 덜 지어서 잃는 것 (−7.5%) 보다 나쁜 경우에 얻는 것 (+10%) 이 크다.
- `c/v = 0.2` 에서는 남는 용량이 싸서 덜 지을 이유가 없다. 얻는 것이 +2% 뿐이다.

**개설비와 같은 손잡이다.** 지금 인스턴스에서 한 점포가 받을 수 있는 예약은 300 이다. 개설비 500 은 단위당 1.67 (`c/v = 0.33`), 개설비 750 은 단위당 2.5 (`c/v = 0.5`) 에 해당한다. 개설비를 올리면 가치가 커진 것 (5 단계) 과 용량비가 클수록 가치가 큰 것 (6 단계) 은 같은 현상이다. 차이는 단위의 크기다. 개설비는 점포 하나 (총 용량의 1/3) 를 통째로 열거나 닫는 결정이고, 용량 단계는 그것을 잘게 조정한다.

## 4. 증거

값은 Belief-only − Nominal, 리더 비용 대비 %, 평균 · 위쪽 꼬리 (q90). 음수면 Belief-only 가 낫다. 소매상 belief 는 진짜 분포에서 `N_F` 개를 뽑은 경험분포다.

| 구성 | 건수 | N_F = 5 | N_F = 20 |
|---|---|---|---|
| 원고 식 (쓴 만큼 정산) | 75 | +0.11 · −0.26 ± 0.14 | +0.07 · −0.12 ± 0.07 |
| 약정, 개설비 500, 입지만 | 75 | +0.27 · −2.29 ± 0.63 | +0.15 · −1.59 ± 0.45 |
| 약정, 개설비 750, 입지만 | 75 | +0.43 · −4.02 ± 0.80 | +0.61 · −2.27 ± 0.55 |
| 약정, 개설비 1000, 입지만 | 75 | +1.95 · −6.04 ± 1.86 | +1.75 · −3.01 ± 0.92 |
| 약정, 작은 점포 6 곳 (한도 150), 개설비 250 | 30 | +0.02 · −0.75 ± 0.40 | +0.04 · −0.94 ± 0.36 |
| 약정, 작은 점포 6 곳 (한도 150), 개설비 500 | 30 | −0.68 · −3.40 ± 1.06 | −0.25 · −3.02 ± 0.95 |
| 약정, A 거점 4 곳 | 30 | +0.43 · −0.15 ± 0.53 | −0.11 · −1.01 ± 0.61 |
| 약정, 입지 + 용량, `c/v = 0` | 30 | −0.15 · −0.82 ± 0.43 | −0.16 · −0.33 ± 0.67 |
| 약정, 입지 + 용량, `c/v = 0.2` | 30 | +1.25 · −2.82 ± 1.55 | +0.96 · −1.80 ± 0.91 |
| 약정, 입지 + 용량, `c/v = 0.4` | 30 | +1.33 · −3.77 ± 1.16 | +2.52 · −2.53 ± 0.73 |
| **약정, 입지 + 용량, `c/v = 0.5`** | 30 | +0.26 · **−5.20 ± 1.31** | +1.80 · **−3.53 ± 0.76** |
| 같은 설정, 용량은 Nominal 과 같게 두고 입지만 (δ = 0.1) | 30 | +0.33 · +0.47 ± 0.52 | +0.20 · −0.13 ± 0.55 |

모두 보정한 반지름 δ* 기준이고 마지막 줄만 δ = 0.1 이다. 고정 δ = 0.1 로 보면 `c/v = 0.5` 는 N_F = 5 에서 −0.09 · −3.69 ± 1.11, N_F = 20 에서 +0.64 · −3.44 ± 0.91 이다.

- **계약 형태.** 원고 식에서 약정 방식으로 가면 Nominal 의 꼬리 피해가 3% 에서 18% 로, 꼬리 우위가 −0.26 에서 −2.3 으로 커진다.
- **입지만으로는 한계가 있다.** belief 를 뽑기마다 아는 리더도 평균 −2.5, 꼬리 −3.5 를 얻는다. 기존 사업자를 강하게 하면 피해는 23% 로 커지지만 우위는 줄어든다.
- **용량이 결정에 들어가면 가치는 용량에서 나온다.** `c/v = 0.5` 에서 Belief-only 는 60~77% 의 실행에서 용량을 7~9% 덜 짓는다 (총 용량 795 → 720~738). 용량을 Nominal 과 같게 두고 입지만 바꾸면 우위가 0 이다.
- **변동 축소의 모양이다.** N_F = 20, `c/v = 0.5`, δ = 0.1 에서 비용의 q95 가 13.1 → 8.7, q05 가 −10.4 → −8.2 로 줄고 평균은 +0.6 오른다.

## 5. 확인하지 않은 것

- 2.2 의 식을 직접 푼 결과가 없다. 거점별 용량 단계에서 우위가 더 커지는지, 그대로인지 모른다.
- 용량 실험은 30 조합 선별이다. 표준오차가 0.8~1.3 이다.
- 리더가 q̂ 를 추정하는 조건의 결과는 개설비 500·입지만에서만 있다 (Belief-only − Nominal 평균 −1.07 ± 0.36, 꼬리 −1.48 ± 0.52). 개설비 750 과 용량 설정에서는 없다.
- 평가는 후보 결정의 열거다. 원고의 알고리즘으로 푼 해가 아니다.
- `c/v` 의 근거 있는 값이 필요하다. 결과를 보고 고른 값이라는 지적을 받을 수 있다. 개설비 750 은 Yanıkoğlu–Kuhn 의 무작위 인스턴스와 원고 계산 실험의 값이다.
- 6 단계의 사전 예측에 적은 비용 규칙 (개설비 500 위에 `c b` 를 더함) 은 `c/v ≥ 0.5` 에서 아무도 열지 않는 사례가 되어 쓰지 못했다. 표의 규칙 (`q_fix = 750 − 300c`) 은 집계 스크립트에 결과를 보기 전에 넣었지만 예측 파일에는 적지 않았다.
- `κ > 0` 과 `f/p = 0.5` 가 우위를 줄이는 원인은 찾지 못했다.

## 6. 결정 기록과 남은 결정

정해진 것 (사용자, 2026-11-14)

- 구조는 약정 물량 방식으로 고정한다.
- 가치 지표는 위쪽 꼬리다.
- 가치 실험의 개설비는 750 으로 하고 500·1000 은 민감도로 싣는다.

남은 것

- 2.2 의 식 (거점별 용량 단계) 을 만들어 75 건으로 확인할지, 식은 2.1 그대로 두고 개설비 750 으로 마무리할지.
- 원고 6.2 절을 약정 방식으로 바꿀지. 바꾸면 `θ^U` 재유도, "남는 물량의 마진도 `v`" 라는 가정의 서술, 알고리즘으로 푼 해의 확인이 필요하다.
