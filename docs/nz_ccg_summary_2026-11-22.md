# 입지 게임 belief 블록 CCG: 하루 논의 총정리 (2026-11-22)

자세한 숫자와 스크립트는 다음 두 문서에 있다.
- `docs/nz_ccg_lazy_cut_findings_2026-11-22.md` (0~18 절, 작업 기록)
- `docs/nz_ccg_why_enumeration_2026-11-22.md` (처음 읽는 사람용 설명, 10~14 절에 식)

이 문서는 둘을 하나의 줄기로 묶는다.

**한 줄 결론.** CCG 의 마스터가 X 를 거의 다 훑는 것은 코드나 정식화의 실수가 아니다. "리더 이진변수가 follower 용량 우변에 들어가는 non-zero-sum 이중수준" 구조에서, 분수 x 에서는 follower 최적성이 사실상 걸리지 않기 때문이다. 오늘 시도한 cut, 정식화, 재인코딩은 모두 이 약함을 고치지 못했다. 좋은 하한 자체는 존재하지만 (볼록 포락으로 0.28%), 그 하한을 만들고 증명하는 도구가 같은 약한 LP 다.

**2026-11-23 정정:** Lagrangian 비용 추정과 원인 서술 일부를 10 절에서 고쳤다. Dantzig–Wolfe 루트로 재면 가격 MILP 6 번으로 루트 0.29% 이지만, 열 단계가 X 의 84% 를 방문한다.

## 1. 문제와 알고리즘

**인스턴스** (loc_tkp, 원고 6.1, 지리 1, 시드 1)
- Coupled-DR r = 0.2, S = 10.
- 리더 (B 소유자) 는 후보 13 곳 × 크기 3 단계 (200·300·400) 에서 최대 3 곳을 연다. x ∈ X ⊂ {0,1}³⁹, |X| = 8,464.
- 소매상 (follower) 은 A·B 점포에 약정 h (모든 시나리오 공통, 약정가 f = 600) 를 정한다. 수요가 실현되면 추가분을 p = 800 에 사고 출하한다. 2 단계 LP 다.
- 리더 손실은 −(B 수입) 이고, follower 비용과 다르다 (non-zero-sum).
- 리더 목적 = 출점비 qᵀx + 최악 (분포, belief) 의 CVaR 손실 V*(x).

**belief 블록** (원고 6 절). belief b 를 고정하면 다음이 V*(x) 의 하한이고, 정수 x 에서 정확하다.

    L_b(x) = min_plan { C_L + μ (C_F − η C_L⁺ − V_F^η(x)) }

- plan 은 follower 결정의 리더 쪽 사본이고, V_F^η 는 follower 쌍대에 McCormick 을 건 것이다.

**pessimistic 처리.**
- follower 목적에 +η·(리더 손실) 을 더해, 동률이면 follower 가 스스로 리더에게 나쁜 해를 고르게 한다 (η ≤ η̄ 가정, η̄ 는 계산하지 않음).
- 그 뒤 min 을 취하므로 구조상 optimistic 이중수준 하나가 된다.
- 최종 값은 섭동 없는 α-B&B oracle 이 확인한다.

**두 가지 판**
- **명시 판:** 블록을 마스터에 통째로 넣는다. 지리 1 전체 X 에서 7,690 s 였다.
- **한 나무 판 (구현, a313847 이후 수정 미커밋):** 블록을 LP cut 생성기로 쓴다. 정수 후보 x̄ 에서 cut t ≥ v + gᵀ(x − x̄) 를 lazy 로 넣는다.
  - 지리 1 은 2,246 s 였고, Lazy = 3 속성으로 바꾸자 **1,465 s** 가 되었다.
  - 지리 15 개 (S = 10, 시드 1) 중 Optimal 14 개, TimeLimit 1 개 (지리 5, oracle 병목) 였다.
  - Stalled 2 건 (지리 8, 13) 은 oracle 하한으로 no-good 을 넣는 수정으로 해결했다.

## 2. 발견: 마스터가 X 를 열거하고 있었다

- 한 나무 판의 정수 후보는 8,510 번 불렸고, 서로 다른 x 는 **8,464 = |X|** 였다.
- 명시 판의 노드는 2,311 = 2·1,156 − 1 이었다 (후보지 7 곳). 잎이 x 하나씩인 완전 이진 나무로, 한 번도 가지를 못 쳤다는 뜻이다.
- 한 나무 판이 5 배 빨랐던 것은 열거를 피해서가 아니라, 같은 열거를 더 가벼운 LP 로 했기 때문이다.
- **문제가 평탄해서가 아니다 (E2).** 최적값 0.5% / 1% / 2% / 5% 안에 드는 x 는 10 / 12 / 23 / 57 개뿐이다.

## 3. 원인을 식으로

### 3.1 블록 (SD 부등식 판, 가격 문제 π = 0 꼴)

```
min   C_L(y) = Σ_s r_s ℓᵀ y_s
s.t.  (P)  A y_s − H h ≤ u_s + Σ_{j,k} b_k x_jk e_cap(j),   W h ≤ w,  0 ≤ h ≤ hᵁ,  y ≥ 0
      (D)  Aᵀ π_s ≥ d_s c + η r_s ℓ,   −Σ_s Hᵀ π_s + Wᵀ κ + ω ≥ c0,   π, κ, ω ≥ 0
      (SD) f^η(h, y) ≥ D = Σ_s u_sᵀ π_s + wᵀ κ + hᵁᵀ ω + Σ_{j,s} π_js Σ_k b_k x_jk
```

- 약쌍대로 f^η ≤ D 이고, (SD) 가 반대 방향을 강제하니 plan 은 follower 최적이다.
- 비선형은 π_js·x_jk 하나뿐이고, 이것을 w ≥ max(0, π − U(1 − x)) 로 건다. 정수 x 에서는 정확하다.

### 3.2 분수 x 는 "사용료" 가 된다

- **분수점에서의 오차:** x = θ 에서 참값은 θπ 이고 McCormick 은 max(0, π − U(1 − θ)) 다. π ≤ U(1 − θ) 이면 0 이 된다. 게다가 π 도 LP 가 고르므로, B 용량 값을 하나도 치르지 않는 쌍대를 고를 수 있다.
- **LP 쌍대로 보면:** D_lin(x) 는 "B 거점 용량 b_k 를 전부 쓰되, 한 단위에 U(1 − x) 의 사용료를 내는 가상의 follower" 의 최적값이다.
  - x = 0.3 이면 사용료 0.7U 라 거의 닫힌 것처럼 행동한다.
  - 반면 plan 은 진짜 용량 0.3b 를 사용료 없이 쓴다.
  - 그래서 (SD) 는 "B 를 거의 못 쓰는 follower 보다만 나으면 된다" 가 되어, 거의 아무 plan 이나 통과한다.

**루트 해부** (가격 MIP, π = 0, 정수 최적 −4,439.17)

| 항목 | 값 |
|---|---|
| 루트 LP | −8,000 = B 용량 1,200 을 전부 추가분 (단가 6.67) 으로 판 값 = HPP |
| z̃ | 13 거점 모두 400 단계에 0.11~0.44 |
| plan 의 follower 손해 | 812,600 (follower 비용이 최적의 약 두 배) |
| 같은 z̃ 에서 진짜 follower 를 최적으로 풀 때의 C_L | −4,644 (4.6% 차) |

**분수 용량이 문제가 아니라, 쌍대 쪽 (사용료) 과 plan 쪽 (용량) 의 어긋남이 문제다.**

### 3.3 Benders cut 의 기울기

- **cut 의 성질:** 부분문제는 정수 x̄ 에서 풀리지만, cut 은 쌍대해 하나에서 나오고 그 쌍대해는 모든 x ∈ [0,1]ⁿ 에서 실행가능하다. 그래서 cut 은 LP 값 ℓ(x) 전체의 접평면이다. x̄ 에서 정확하다는 것은 절편만 보장하고, 기울기는 분수 x 에서의 감도로 정해진다.
- **곱 항 하나를 x̄ 에서 미분하면:**
  - x̄ = 1 이면 참값의 미분은 π 인데 McCormick 은 **U** 다.
  - x̄ = 0 이면 참값은 π 인데 McCormick 은 **0** 이다.
- **열린 거점을 닫는 방향의 기울기:** g_j ≈ (승수 μ 또는 SD 승수) × b_k × Σ_s U_js 다. 벌점 판에서는 10 × 400 × 10³ ≈ 4 × 10⁶ 이고, 실제 이웃 사이 값 차이는 약 10³ 이다.
  - 측정 (11-21 문서, 원고 Algorithm 1 의 cut): 기울기 −10⁶ ~ −10⁷.
  - 같은 점의 Lagrangian cut 은 기울기 최대 295 였다. 차이는 "분수 x 에서도 유효해야 하느냐" 하나다.
- **인스턴스에 따른 차이:** 가파름 배율 ≈ (교환 비율) × π^U / (리더 단가) 다.
  - π^U (follower 의 거점 비용 이점 상한) 는 지리 15 개에서 920 ~ 4,380 이고, 중앙값은 1,380 ~ 3,500 이다. 그래서 지리 사이 차이는 2~3 배다.
  - θᵁ = 0.667 은 거리가 10 단위로 반올림되어 있어 모든 지리에서 같다.
  - zero-sum 이면 교환 비율이 0 이라 이 문제가 없다.
- **정규화:** 배율, 루트, 노드 수가 모두 단위에 무관하다. 정규화는 수치 안정성만 바꾼다.

## 4. cut 쪽 시도

| 시도 | 결과 |
|---|---|
| 블록 약쌍대 (wd) | 루트 −8.4e6 → −5,150, 후보 수 그대로 |
| MW (Pareto) | 10~20% 강할 뿐, 후보 수 그대로, 2 배 느림 |
| interdiction (단조성) cut | 블록이 plan 의 최소화라 LP cut 과 같아짐 |
| 거점 쌍 곱 cut | 강하지만 분리 450~480 번 (\|X\| 의 40%) |
| **사슬 submodular cut** | t ≥ L(S) − Σ_{j∈S} ρ̄_j(S)(1 − x_j) + Σ_{j∉S} ρ_j^min x_j |

사슬 submodular cut 의 경과는 다음과 같다.
- **정의만으로 유효합니다.** ρ_j^min 자리에 ρ_j(∅) 를 쓰자 지리 1 이 1,465 s → 753 s 가 되었다.
- **그러나 ρ_j^min = ρ_j(∅) 조건은 거짓이었다.** 지리 15 개 × belief 3 개 × μ 2 개 = 90 조합 중 82 개에서 위반됐다 (거점 보완 관계).
- **정확한 ρ_j^min:** 삼중 집합 (X 의 91%) 의 값이 필요하다. MILP 로 구하면 노드가 V 후보 수의 약 2 배라 이것도 열거다.
- 외부 검토 의견: 사슬 cut 은 x 에 아핀이라 볼록 포락보다 강할 수 없다.

## 5. 좋은 하한은 있다 (E1)

    ℓ_b (블록 LP, 꺼짐)  ≤  Ľ_b (X 위 볼록 포락 = Lagrangian cut 의 천장)  ≤  L_b

- 블록 11 개의 볼록 포락 하한은 −1,633.94 이고, 정수 최적 −1,629.42 와 **0.28%** 차이다 (허용오차 0.5% 안).
- 이상적 분리로 30 라운드, cut 269 개면 허용오차 안에 든다.

## 6. Lagrangian 경로의 비용

**cut 분리.** 볼록 포락 cut t ≥ a + πᵀx 를 만들려면 가격 문제를 풀어야 한다.

    a ≤ min_{z ∈ X} [L_b(z) − πᵀz]

이 가격 문제는 **블록 하나짜리 마스터 (이중수준 MIP)** 다.

**가격 MIP 가 느린 이유** (Gurobi 로그, π = 0)
- 루트 하한은 −8,000 (3.2 의 HPP) 이고, 최적 −4,439 는 루트 휴리스틱이 바로 찾는다.
- 노드는 15,656 ≈ 1.85|X| 개이고, 노드당 1.3 ms 로 약 20 s 다. **시간은 전부 하한 증명에 든다.**
- 걸리는 시간은 이진변수 39 개라는 숫자가 아니라 |X| = 8,464 에 비례한다. 그래도 8,464 점을 LP 로 하나씩 평가하는 것 (약 130 s) 보다는 빠르다.
- 일찍 멈출 수 없다. 절편으로 필요한 것이 그 하한이기 때문이다.
- 그런데 cut 하나에 가격 MIP 를 약 30 번, cut 은 약 270 개 필요하다. 열을 재사용해도 약 1.5 시간, 처음부터 하면 약 42 시간이다.

**싼 판들**

| 판 | 결과 |
|---|---|
| Strengthened Benders (LP 기울기 + MIP 절편) | 기울기가 가팔라서 루트 −6.66e6 |
| 부정확 Lagrangian (Kelley, K = 3·5·10) | 가격 MIP 946~5,909 번에 루트 −13,350 (천장의 7 배 아래) |
| 가격 MIP 에 wd | 노드 18,762 → 14,265, 시간은 20.2 → 24.9 s 로 늘어남 |

**왜 루트가 움직이지 않는가.**
- follower 최적성을 "f^η(plan) ≥ g(x), g 는 x 의 볼록함수이고 X 위에서 유효" 한 줄로 거는 판은 모두 g ≤ φ̌ (정수점 φ 의 볼록 포락) 다. 벌점, SD, 약쌍대, 값함수 cut, Lagrangian, Benders binary cut 이 여기에 속한다.
- 이상적인 φ̌ 판의 루트가 −8,000 이므로, 이 꼴은 루트를 못 올린다. 분기한 뒤 노드에서만 줄인다 (상한 1,747~2,490 노드).
- 루트를 올린 것은 plan 의 성분과 x 를 직접 묶은 교환 부등식 하나다.

**x 재정식.**
- {Σ o_j ≤ 3, Σ_k x_jk ≤ 1} 은 이미 conv X 다. 그리고 루트 해는 400 단계 하나에서 개설 자체가 분수다.
- 그래서 단계별·누적·개설 어느 인코딩이든 McCormick 이 같아지고, 바뀌는 것은 분기뿐이다 (노드 29% 감소).
- 끝까지 밀면 plan = Σ_t λ_t·(배치 t 의 follower 최적 plan) 꼴이 되는데, 이것은 배치 열거다.

**코드 점검 (이상 없음).**
- g ∈ [200, 400] 가 모두 양수라 McCormick 한쪽으로 충분하다.
- 섭동 부호가 pessimistic 방향이다.
- 거점당 단계 하나 제약이 들어 있다.
- 정수점 값이 McCormick 없는 독립 구성과 일치한다.

| Bolusani–Ralphs (Math. Program. 2022) | 일반화 Benders. primal function 이 기저 영역에서만 유효해 지시 이진으로 전환. 계산 결과 없음 | 값함수 cut 과 같은 꼴 → 루트 못 올림 |
| Tahernejad–Ralphs, MIBLP 부등식 (COR@L 20T-013-R1) | 약함의 원인을 d²y ≤ φ 의 완화로 짚음. Benders binary cut 은 단조성으로 상위 집합 전체에 유효 | 시험함 (7 절): 루트 그대로 |
| Lozano–Smith (Oper. Res. 2017), Lozano–Bergman–Cire (2024) | 값함수 cut | 최선이 φ̌ (7 절) |
| Kleinert 외 (2021) | 부등식 | 우리 구조에서는 McCormick 과 같아짐 |
| Grötschel–Lovász–Schrijver | conv 위 분리 ≡ 최적화 | 공짜 cut 은 없다는 원리 |

## 9. 결론과 남은 결정

**확실해진 것**
1. 약함의 원인은 하나다. 분수 x 에서 McCormick 이 쌍대를 용량 값에서 풀어 주어, 루트가 HPP 와 같아진다. Benders 기울기, 마스터 열거, 가격 MIP 의 느림이 모두 여기서 나온다.
2. 이것은 non-zero-sum 이중수준 + 용량형 연결의 구조적 성질이다. 인스턴스는 배율을 2~3 배 바꿀 뿐이고, 정규화로는 바뀌지 않는다.
3. 좋은 하한 (볼록 포락, 0.28%) 은 있다. 하지만 그것을 만드는 가격 문제가 같은 약한 LP 로 X 를 증명해야 한다.
4. CCG 가 실제로 하는 일은 "비싼 oracle (분) 대신 싼 블록 LP (ms) 로 X 를 훑고, oracle 은 몇 번만 부른다" 이다. |X| = 8,464 에서는 실용적이었다.

**남은 결정 (사용자)**
- **원고 서술:** "열거형이지만 싼 LP 로 하는 CCG" 로 한계까지 정직하게 쓸지, 이 계열을 주 알고리즘에서 내릴지 정해야 한다. 마스터를 값 표 (한계를 둔 열거) 로 바꾸는 것도 비교 기준 후보다.
- **작은 개선:** 누적 단계 인코딩 (노드 약 30% 감소) 과 교환 부등식 (입지 전용) 을 솔버에 넣을지 정해야 한다.

**별도 병목과 부수 사실**
- **oracle (α-B&B):** 지리 5 는 한 번에 약 6,500 s 걸렸다. 원인은 follower belief × 반응의 곱 (α·d) 의 McCormick 이고, 노드별 belief 범위 조이기 (OBBT) 가 후보다 (시작 전).
- **정밀도 증폭:** CCG 허용오차 0.5% 는 총목적 (약 1,300) 기준이라, oracle 값 (약 3,150) 에는 약 0.19% 의 상대 정밀도가 필요하다.
- **λᵁ:** 100 → 10 으로 바꿔도 oracle 상한 궤적이 같았다.
- **미커밋:** a313847 이후의 솔버 변경 (사슬 cut 옵션, MW, Lazy = 3 기본, belief 목록 저장, Stalled 수정) 과 오늘의 문서들은 커밋하지 않았다.

### 10.2 Dantzig–Wolfe 루트 실측 (지리 1 전체 X, 최종 belief 11 개 고정, `scratchpad/dwroot.jl`)

**방법.**
- 제한 마스터 (RMP): min qᵀx + t, t ≥ Σ_z λ^b_z L_b(z) (블록마다), Σ_z λ^b_z z = x (블록마다), Σ_z λ^b_z = 1. 열은 X 의 점 z, 비용은 블록 LP 값 L_b(z).
- 휴리스틱 가격: t 행 쌍대 w_b > 0 인 블록만, 그 블록의 지지 열 이웃을 블록 LP 로 평가한다. w_b = 0 인 블록은 X 위 선형 가격이라 탐욕으로 푼다.
- 정확 가격: 휴리스틱이 막히면 w_b > 0 블록마다 가격 MILP min_z w_b L_b(z) − π_bᵀz (블록 + 이진 z) 를 푼다. BestBdStop = σ_b − tol 로 "음의 환원비용 없음" 만 증명한다.
- Farley 하한 = RMP + Σ_b min(0, 가격 하한 − σ_b). 임의의 쌍대 실행가능 (w, π) 에서 유효하다.
- 이 하한은 블록별 Lagrangian cut t ≥ a_b + (π_b / w_b)ᵀx, a_b = min_z [L_b(z) − (π_b / w_b)ᵀz] 를 w 로 묶은 것과 같다. 가격 MILP 한 번이 cut 하나의 절편 증명이다.

**결과.**

| 항목 | 값 |
|---|---|
| Farley 하한 / 정수 상한 | −1,634.15 / −1,629.42 (표의 정수 최적과 같음) |
| 간격 | **0.290%** (허용오차 0.5% 안, 분기 없음) |
| 가격 MILP (= 필요한 Lagrangian cut) | **6 번, 44 s** (평균 7.3 s, 노드 평균 약 6,300) |
| 열 단계 | 블록 LP 약 45,000 번, 8 스레드로 약 240 s |
| 방문한 서로 다른 점 | 7,082 (X 의 84%) |
| 마스터 합계 | 약 310 s (생성기 구성 23~39 s 제외) |
| 검증 | 캐시 값과 표의 최대 차 1.4e-7 |

**함정 둘.**
1. 가격 MILP 에는 솔버와 같이 IntFeasTol 1e-9, IntegralityFocus 1 이 필요하다. 기본값이면 McCormick 계수 (약 10⁶) 로 가짜 해가 나올 수 있다.
2. RMP 가 이미 최적값인데 쌍대 퇴화로 쌍대가 최적면 위를 옮겨 다녀, 정확 가격이 같은 크기의 음의 환원비용 열을 계속 내놓는다. RMP 를 barrier, crossover 끔으로 풀면 해결된다 (표 시험: 정확 라운드 23 → 10). Wentges 평활은 효과가 없었다.

**열 단계를 줄이면 (표 시험).** 이웃을 표본으로 줄이면 블록 LP 는 줄지만 가격 MILP 가 는다.

### 10.3 판정

- 비용 추정 (1.5~42 시간) 은 과대였다. 실측은 증명 6 번 (44 s) 이다.
- "증명 도구가 약한 블록 LP 라 \|X\| 에 비례한다" 는 9 절의 결론은 맞다. 이번에는 증명이 아니라 열을 찾는 단계가 X 의 84% 를 방문한다.
- 같은 블록의 lazy 한 나무 재풀이 (약 128 s, `nz_belief_block_ccg.md` 의 lazy_attr = 3 실행) 보다 느리다. 얻는 것은 분기 없는 루트 인증이다.
- 한계: 지리 하나, belief 고정. CCG 안에서 belief 가 늘 때 열을 다시 쓰는 효과는 재지 않았다.
- **2026-11-23 후속:** CCG 전체를 DW branch-and-price 로 푼 시험과 η 유효성 단서 (η = 0.1 이 η̄_b 를 넘어 블록이 V* 보다 클 수 있음, 이 문서의 결론에도 해당) 는 `docs/nz_ccg_bnp_2026-11-23.md`.
